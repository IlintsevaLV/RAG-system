# Двойники, порог каши и порядок строк

**Дата:** 2026-10-02

После ночного прогона (отчёт `2026-10-02_retrieval_test_report.md`) в индексе 8813 страниц A/B и около 30 тысяч чанков. `probe` был 98/100. Два отдельных дефекта: греческая `η` между латинскими подписями и схема «Классификация самолетов» со score 4.7. Одноколонный текст РЦ-АП-ВД 6.3 резался по середине страницы.

Формулы по-прежнему не индексируются. Ответ — текст чанка и место в документе. Генерации нет. RapidOCR mobile остаётся распознавателем по умолчанию.

## Нормализация

`normalize_greek_lookalikes` по-прежнему смотрит на ближайшую настоящую букву. Цифры, пробел, пунктуация и знаки вроде `§` прозрачны: смотрим дальше, до буквы. Знак формулы (`=`) по-прежнему блокирует замену.

- `η` становится `и`, если рядом нет знака формулы. Соседняя латиница больше не оставляет её греческой: `(O) η caveat` → `(O) и caveat`.
- Заглавные в русском заголовке читаются кириллицей: `(Α)` → `(А)`, `(Β)` → `(В)`, `(Δ)` → `(Д)`, плюс `Ε Η Ι Κ Μ Ο Ρ Τ Υ Χ Γ Θ Λ Ξ Π Σ Φ Ψ Ω`.
- Строчные маркеры списка: `(χ)` → `(в)`, `(δ)` → `(г)`, `(φ)` → `(ф)`, `(γ)` → `(г)`.
- `(ι) ОЦЕНКА` → `(i) ОЦЕНКА`. Вне скобок `ι` выбирается по соседней букве.
- Между цифрами без латинского слова буква берёт кириллический двойник: `β § 29.501(α)(3)` → `в § 29.501(а)(3)`. Одинокая `α` без цифр остаётся греческой.
- Сокращения: `τ.δ.` → `т.д.`, `τ.ε.` → `т.е.`, `τ.κ.` → `т.к.`. `ε.γ.` по-прежнему `e.g.`.
- Код из заглавных букв и цифр остаётся латиницей: `Σ1000Δ` → `S1000D`. Формула `σ = μ + λ` не меняется.

Повторный `probe` на этом снимке: 98 из 99. Оставшийся промах — повторяющаяся строка «178.68 главы С Свода федеральных правил 49 CFR», не греческая буква. Шапка «Глава 4.3» из ночного отчёта в эту выборку не попала.

## Порог и каша

Чанк, у которого больше половины непустых строк короче 20 знаков, или больше 30% строк короче 5 знаков, или на длинном тексте меньше двух запятых и точек на 1000 знаков, получает множитель 0.5 к BM25. Флаг `likely_table` не используется: он стоит на 68% страниц A/B. Короткий пункт из пары строк штрафом не помечается.

У команды `query` порог `--min-score` по умолчанию 5 и действует только в лексическом режиме. Ниже порога ответ «В корпусе не найдено». `--min-score 0` порог выключает. `probe` и `eval` порог не ставят: самопроверка не должна отбрасывать верное, но слабое совпадение.

На собранном индексе «Классификация самолетов» даёт 2.35 (после штрафа; в ночном отчёте было 4.7) и с порогом 5 не возвращается. «Требования к прочности» остаётся 10.78, ФАП-118, пункт 3.

Гибрид по-прежнему смешивает более мягкий лексический список: треть слов вопроса или технический код вроде `ARP4754A`. Строгий лексический ответ по-прежнему требует номер пункта или половину слов.

## Порядок строк

`reorder_spans_by_columns` больше не делит страницу по вертикали посередине. У обычного абзаца слова стоят и слева, и справа от центра, и прежняя проверка собирала все левые половины, потом все правые. Так рвалась страница 7 РЦ-АП-ВД 6.3.

Две колонки включаются, только если в строке есть разрыв не уже 8% ширины листа и этот разрыв пересекает середину. Слова одной строки с дрожанием верха до 4 pt остаются в одной строке. Уже записанный `page_0007.txt` не переписывается: порядок появится после повторной вычитки PDF.

## OCR

`OCR_ENGINE=rpd` и флаг `--ocr-engine rpd` оставляют `cyrillic_PP-OCRv5_rec_mobile`. `rpd_server` переключает RapidOCR на `cyrillic_PP-OCRv5_rec_server.onnx`. В каталоге RapidOCR 3.9.2 такого файла нет: опубликован mobile для кириллицы и server для китайского, английского и японского. Пока файла нет в `data/models/ocr`, `rpd_server` не стартует. `paddle`, `easy` и `tess` флаг принимает и сразу завершается с кодом 2. На этой машине нет GPU. В журнал страницы пишутся `ocr_engine` и `elapsed_ms`. Сверка пяти страниц ФАП 273: `python -m scripts.eval_fap273_ocr`.

## Эталоны

- `data/ir/gold/retrieval_v1.json` — десять дословных вопросов и три вопроса не из корпуса (`relevant: false`).
- `data/ir/gold/retrieval_v1_para.json` — те же пункты перефразом и те же три отсутствующих вопроса.
- `data/ir/gold/retrieval_v1_paraphrase.json` — второй набор из десяти перефразов без отсутствующих вопросов.

Пустой ответ на `relevant: false` считается попаданием.

## Как прогнать

```powershell
python -X utf8 -m retrieval check
python -X utf8 -m retrieval build
python -X utf8 -m retrieval probe
python -X utf8 -m retrieval query "Классификация самолетов"
python -X utf8 -m retrieval query "требования к прочности"
python -X utf8 -m retrieval query "Классификация самолетов" --min-score 0
```

Индекс `data/cache/text_index` в git не входит. После `git pull` на рабочем ПК индекс нужно собрать заново, иначе в чанках останется прежняя греческая `η`.
