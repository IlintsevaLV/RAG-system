# Фиксы по weekend run и roadmap (2026-09-28)

Контекст: `2026-09-28_weekend_run_summary.md`, `2026-09-28_problems_and_roadmap.md`.
Прогон 33/35 PDF, 6694 страницы. Эвристики caption/ink не тюнил: на golden v2 они дают P=0.28, рабочий путь — Docling.

## Рисунки (Issue 20, остаток)

- Угловой логотип меньше 100×100 pt отбрасывается (`is_corner_logo`). Это ложные FAA-марки на титулах rdk89.
- Панели одной фигуры склеиваются, если пересечение по x больше 50% и зазор по y меньше 30 pt (`merge_picture_panels`). Составной Fig. 1.1 больше не должен распадаться на три объекта.
- Подпись длиннее 180 символов без «Фиг./Fig.» в начале не привязывается (абзац страницы). OCR-caption обрезается до 300 символов (Issue 19).
- Два красных unit-теста (`unexpected docling hits`, `pdf leaked`) проверяли отсутствие Docling. На рабочем ПК модель стоит, поэтому тесты падали. Вместо них — проверки логотипа и склейки панелей, без вызова модели.

## Формулы (Issues 10, 12, 13, 14)

- Склейка фрагментов требует оператор, дробь или греческую букву. Цепочки `f. g.` / `a. b.` больше не становятся формулой (Issue 12).
- Строка только из `_`, `-`, `=` не формула (Issue 13).
- Рамка формулы дотягивается вправо до соседнего спана в пределах 40 pt, если дробь обрезана (Issue 10).
- В сводке страницы есть `formula_suspicious`, в CLI печатается `susp=` рядом с `ok` и `sem` (Issue 14).

## Прогон (баги A, B, C)

- `doc_id` обрезает пробел и точку в конце имени. Папка `ФАП 273 правила допуска к эксплуатации ` больше не ломает запись crop (баг A).
- `run_regions` пишет JSON пачками по 200 страниц и вызывает сборку мусора. Длинный PDF не держит все страницы в одном проходе до конца (баг B).
- `--resume` пропускает PDF, у которого в JSON уже есть все запрошенные страницы.
- `--merge` дописывает недостающие страницы, не затирая уже посчитанные.
- stdout/stderr принудительно UTF-8, чтобы `⁶` не ронял консоль cp1251 (баг C). То же в `run_extract_pages`.

## Что не делалось

- Golden на 100+ страниц, PP-DocLayout, VLM для 607 мусорных страниц, picture classifier. Это следующие этапы roadmap, не правки кода по фактам прогона.
- Повторный прогон `АС 1.1.S1000DR_2014` и `ФАП 273` — только на рабочем ПК.
