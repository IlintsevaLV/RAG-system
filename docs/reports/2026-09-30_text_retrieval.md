# Поиск по тексту классов A и B

**Дата:** 2026-09-30

Формулы, таблицы и рисунки в этот контур не входят. Ответ — точный текст чанка и место в документе. Генерации нет.

## Что сделано

Страницы читаются из `data/ir/pages/*_pages.json`. В индекс попадают только класс A или B, статус `ok`, без `low_confidence` и без `garbage_veto`. Оглавление с точечными лидерами отбрасывается. Файлы `page_XXXX.txt` не индексируются: в них нет класса страницы.

Текст режется по номерам пунктов (`27.1435.`, `2.5.2 Примеры`, `Глава 4`, строка `1.` и заголовок на следующей строке). Подпункты `(a)` / `а)` остаются внутри пункта. Продолжение на следующей допущенной странице цитируется одним чанком с диапазоном страниц. Перенос `си- / стема` склеивается. Пункт длиннее 1800 знаков делится на фрагменты с тем же номером.

Поиск лексический (BM25). Чанк возвращается, если в вопросе назван его номер или в нём есть не меньше половины слов вопроса и хотя бы два таких слова. Иначе ответ: «В корпусе не найдено». Плотные векторы не строились. Их включает `python -m retrieval build --dense` при установленном `sentence-transformers` и модели `intfloat/multilingual-e5-small`.

## Проверка на этой машине

В `*_pages.json` здесь 41 страница, не весь корпус: 13 JSON пустые. После `build`: допущено 24 страницы A/B, 90 чанков, 15 документов.

- `python -m retrieval check` — синтетика нарезки и отказа, проходит.
- `python -m retrieval probe` — 80 проб, recall@5 = 1.0. Проба берёт предложение из чанка и проверяет, что исходные документ, пункт и страница есть в top-5.
- Запрос «гидравлические системы 27.1435» → НЛГ-27, страница 83, пункт 27.1435.
- Запрос «полеты EDTO при отказе критически важной системы» → ИКАО Приложение 6, страница 83, глава 4.
- Запрос вне корпуса → «В корпусе не найдено».

Полный корпус появится, когда на рабочем ПК в `data/ir/pages` будут полные JSON. Команда сборки та же.

## Как прогнать

```powershell
python -X utf8 -m retrieval check
python -X utf8 -m retrieval build
python -X utf8 -m retrieval probe
python -X utf8 -m retrieval query "гидравлические системы 27.1435"
python -X utf8 -m retrieval query "квантовая телепортация марсианского двигателя"
```

Индекс: `data/cache/text_index` (в git не входит).
