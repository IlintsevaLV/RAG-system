## 🔴 Issue 1: `span_cells` пропускает обычный текст как таблицу

**Приоритет:** высокий
**Трудозатраты:** 2–4 часа
**Файл:** `ingestion/region_detect.py`

### Проблема

Детектор `span_cells` выдаёт «таблицы» на обычном тексте. На `_1954.pdf` — **7 ложных срабатываний** из 34 тестовых страниц.

**Стр. 24** — двухколоночный текст:
```
| С ТОЧКИ | зрения веса, но дороги и пногда | $ΠΡΟΥ3ΒΟΔΑΤ ΜΗΟΓΟ μ
```

**Стр. 37** — текст с формулами (3 ложные таблицы):
```
| | $μ =$ | W | | | м | | N | | $= CN.$ |
| | Основным недостатком | | | ΠΡΗΜεεΗΗΑ | | | теоремы |
| Для | | определения результирующей | | | скорости потока |
```

**Стр. 190** — плотный текст (3 ложные таблицы):
```
| | В настоящей | главе | | рассматривается | − | срыв на лопастях |
| H3 $cΚΑ3aΗΗΟΓΟ$ | | ясно, что срыв должен | | всегда | | наступать |
| потока сквозь | | диск снизу вверх | (автожирный | режим) | | $ΗαΓργ3κα$ |
```

### Гипотеза

`span_cells` видит «ячейки» из слов, выровненные в колонки — и классифицирует как таблицу. Порогов для отсева нет.

### Фикс

Добавить в `region_detect.py` проверки **перед** финализацией table-региона:

```python
def is_real_table(spans, page_width, page_height):
    # 1. Минимум 2 колонки и 2 строки
    if n_cols < 2 or n_rows < 2:
        return False

    # 2. Ширина > 30% страницы
    if bbox_width < 0.3 * page_width:
        return False

    # 3. Numeric ratio (для таблиц с числами)
    numeric_ratio = count_numeric_cells / total_cells
    if numeric_ratio < 0.3:
        return False

    # 4. Выравнивание колонок (дисперсия x-координат)
    col_std = stdev(x_left_per_column)
    if col_std > threshold:
        return False

    # 5. Не более 50% пустых ячеек
    empty_ratio = count_empty_cells / total_cells
    if empty_ratio > 0.5:
        return False

    return True
```

**Дополнительно:** `span_cells` уже считает `numeric_ratio`, `consistency`, `meaningful`. Использовать их как готовые признаки.

## 🟡 Issue 2: OCR ячеек путает кириллицу с греческими

**Приоритет:** средний
**Трудозатраты:** 3–6 часов
**Файлы:** `ingestion/table_pipeline.py`, `ingestion/ocr_rapid.py`

### Проблема

В таблице на стр. 61 `el`-голова сработала на кириллице:
```
| Суженне | $Β Γραπγcαx$
```

- `Суженне` — должно быть `Сужение` (OCR-ошибка)
- `Γραπγcαx` — кириллица **распознана как греческие буквы**

### Гипотеза

Для каждой ячейки запускаются **все три головы** (cyrillic + latin + el). `el`-голова возвращает результат даже на кириллическом тексте, а merge-логика принимает её результат.

### Фикс

Для ячеек таблиц **без math-маркеров** использовать **только cyrillic-голову**:

```python
def pick_ocr_heads_for_cell(cell_text_hint):
    """Определяет, какие OCR-головы использовать для ячейки."""
    has_math = any(ch in cell_text_hint for ch in "=+−×÷^_√∫∑")
    has_latin = any(ch.isascii() and ch.isalpha() for ch in cell_text_hint)
    has_digits = any(ch.isdigit() for ch in cell_text_hint)

    if has_math or (has_digits and not has_latin):
        return ["cyrillic", "latin", "el"]  # формула/число — все головы

    # обычный текст — только cyrillic
    return ["cyrillic"]
```

**Альтернативно:** ужесточить `tech_symbols._CYR_TO_GREEK_MATH` — применять только внутри формул (`$...$`), не в обычном тексте.

### Проверка

```powershell
& $PythonMain -m ingestion.run_regions $Pdf --pages 61,68,69,189 --out-dir "data\ir\page_tests\T6_real_tables"
& $PythonMain scripts\inspect_tables.py data\ir\page_tests\T6_real_tables\_1954_regions.json
```

**Ожидаемо:** `Сужение` вместо `Суженне`, `Γραπγcαx` отсутствует.

## 🟢 Issue 4: Дублирование formula и table на одной области

**Приоритет:** низкий
**Трудозатраты:** 1–2 часа
**Файл:** `ingestion/region_detect.py`

### Проблема

Стр. 3 — таблица опечаток и **отдельная формула** из той же таблицы:
```
[table]   | Crp. | Cτροκα | Напечатано | Должно быть |
[formula] \scriptstyle \theta _ { i } = \theta _ { K y...
```

Формула `θ_i = θ_Ку...` — это содержимое ячейки таблицы, но детектится как отдельный formula-регион.

### Фикс

Подавлять formula-регионы, чей bbox **полностью внутри** bbox table-региона:

```python
def suppress_formulas_inside_tables(formulas, tables):
    result = []
    for f in formulas:
        inside = any(
            f.bbox.x1 >= t.bbox.x1 and f.bbox.x2 <= t.bbox.x2
            and f.bbox.y1 >= t.bbox.y1 and f.bbox.y2 <= t.bbox.y2
            for t in tables
        )
        if not inside:
            result.append(f)
    return result
```

### Проверка

```powershell
& $PythonMain -m ingestion.run_regions $Pdf --pages 1,2,3 --out-dir "data\ir\page_tests\T1_title"
```

**Ожидаемо:** `formula=0, table=1` на стр. 3.

**Приоритет:** низкий
**Трудозатраты:** 1–2 часа
**Файл:** `ingestion/region_detect.py`

### Проблема

Стр. 25 — `figure_00` содержит формулу `\begin{array}{rl} \cdots^{mm \times n...`, а не рисунок. При этом **та же область** детектится как `formula_00`. Двойная классификация.

### Фикс

Отвергать figure-регионы, где:
1. `span_math_heuristic` даёт высокий score (> 0.7).
2. Площадь региона < 5% страницы.

```python
def is_real_figure(region, math_score, page_area):
    if math_score > 0.7:
        return False
    if region.area < 0.05 * page_area:
        return False
    return True
```
