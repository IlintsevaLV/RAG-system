## Открытые issues

### Issue 10 (средний): bbox формул режет длинные дроби

Формулы `M = Φ/Φ`, `q = 37,5 i`, `c_τ = ds_τ/ds` получают bbox, который
обрезает правую часть. Проблема в `detect_formula_regions_from_spans` —
bbox не расширяется вправо на фрагменты длинных выражений.

**Файл:** `ingestion/region_detect.py`, `detect_formula_regions_from_spans`.

**Предложение:** расширять bbox вправо до ближайшего текстового span'а
или до конца ink-блока.

### Issue 12 (высокий): merge_formula_spans склеивает короткие текстовые фрагменты

`f. g.`, `a. b.`, `h. i.` — короткие текстовые фрагменты воспринимаются как
псевдо-формулы. На rdk89 p100 — 5 из 6 ложных. После фикса OCR-голов
проблема усилилась: T3 formula 28→30.

**Night_run_v2 показал: 65-70% ok-формул — merge-склейки (rdk89: 184 ok,
usarmy: 172 ok — большинство ложные).**

**Файл:** `ingestion/formula_pipeline.py`, `merge_formula_spans`.

**Предложение:** требовать, чтобы merged span содержал хотя бы один
"формульный" символ (=, +, −, ∫, ∑, греческие буквы). Чисто текстовые
склейки отсеивать.

### Issue 13 (низкий): горизонтальные линии как формулы

На `icao_annex6 p200/300` горизонтальные линии детектируются как формулы с
`text=_____`, `latex='-'`.

**Предложение:** фильтр по `text` — если строка состоит только из `_`, `-`,
`=`, `.` — не формула.

## Инфраструктура

### Работает стабильно

- `run_extract_pages` — текст страницы.
- `run_regions` — таблицы (Docling), рисунки (Docling).
- `check_figure_detect.py` — метрики фигур, unit-тесты.
- `gold_mark_helper.py` — разметка golden.

### Известные баги инфраструктуры

- PowerShell 5 не поддерживает `<` redirect. Использовать `--append-to` или
  `Get-Content -Raw | ...`.
- `import fitz` даёт warning. Использовать `import pymupdf as fitz`.
- Pipe между двумя `& $PythonMain` не пробрасывает stdout/stderr. Обходить
  через файлы-посредники.

## Приоритеты на следующую итерацию

1. **Figure detector:** фильтр логотипов + merge панелей (см. отдельный отчёт).
2. **Formula merge:** требовать формульный символ в merged span (Issue 12).
3. **Formula bbox:** расширять вправо длинные дроби (Issue 10).
4. **Figure caption:** ограничивать длину (Issue 19).
5. **Прогон корпуса** через Docling + замер скорости.

## Риски

- **UniMERNet в subprocess** — если упадёт на одной странице, может обрушить
  весь прогон. Weekend-скрипт изолирует падения по PDF, но не по странице
  внутри PDF.
- **Docling CPU-скорость** — неизвестна на больших PDF. Может занять больше
  суток на всём корпусе.
- **VLM отключён** — если для каких-то PDF понадобится, качество будет ниже.
