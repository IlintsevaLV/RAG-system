\## ⚠️ Проблемы



\### 1. Ложные таблицы на тексте (высокий приоритет)



\*\*Стр. 24\*\* — двухколоночный текст → `table\_00`:

```

| С ТОЧКИ | | | зрения веса, но дороги и пногда | | | | $ΠΡΟΥ3ΒΟΔΑΤ ΜΗΟΓΟ μ

```



\*\*Стр. 37\*\* — текст с формулами → \*\*3 ложные таблицы\*\*:

```

| | $μ =$ | W | | | м | | N | | $= CN.$ |

| | Основным недостатком | | | $ΠΡΗΜεεΗΗΑ$ | | | теоремы о количестве |

| Для | | определения результирующей | | | скорости потока |

```



\*\*Стр. 190\*\* — обычный текст с греческими вставками → \*\*3 ложные таблицы\*\*:

```

| | В настоящей | главе | | рассматривается | | − | срыв на лопастях и его |

| H3 $cΚΑ3aΗΗΟΓΟ$ | | ясно, что срыв должен | | всегда | | наступать | | на |

| потока сквозь | | диск снизу вверх | (автожирный | режим) | | $ΗαΓργ3κα$ |

```



\*\*Паттерн:\*\* текст разбивается на «ячейки» по словам/пробелам, детектор `span\_cell\_grid` видит выравнивание и классифицирует как таблицу.



\*\*Фикс (рекомендация):\*\*

1\. Требовать \*\*минимум 2 колонки\*\* (`n\_cols >= 2`).

2\. Требовать \*\*минимум 2 строки\*\* (`n\_rows >= 2`).

3\. Требовать, чтобы таблица занимала \*\*> 30% ширины страницы\*\*.

4\. Проверять \*\*выравнивание по столбцам\*\* — дисперсия x-координат левого края ячеек в колонке < порога.

5\. Отвергать таблицы, где \*\*> 50% ячеек пустые\*\* (`| | | |`).



\### 2. OCR-мусор в ячейках реальной таблицы (средний приоритет)



\*\*Стр. 61\*\* — таблица с характеристиками:

```

| 1 \\| | Крутка | CT | cr$ |

| Суженне | $Β Γραπγcαx$

```



\- `Суженне` — должно быть `Сужение` (OCR-ошибка).

\- `$Β Γραπγcαx$` — кириллица распознана как греческие символы, `Γραπγcαx` — каша.

\- `cr$` — незакрытый LaTeX-фрагмент.



\*\*Гипотеза:\*\* `el`-голова сработала на кириллическом тексте внутри ячейки и вернула греческие буквы вместо русских.



\*\*Фикс:\*\*

1\. Пост-фильтр: если в ячейке смешаны кириллица и греческие \*\*без math-контекста\*\* — отдавать приоритет кириллице.

2\. Ужесточить `tech\_symbols.\_CYR\_TO\_GREEK\_MATH` — применять только внутри формул (`$...$`), не в обычном тексте.

3\. Для ячеек таблиц использовать \*\*только cyrillic-голову\*\*, если в регионе нет явных math-маркеров.



\### 3. Дублирование формулы и таблицы (низкий приоритет)



\*\*Стр. 3\*\* — таблица опечаток + формула `θ\_i = θ\_Ку...` из той же таблицы:

```

\[table] | Crp. | Cτροκα | Напечатано | Должно быть |

\[formula] \\scriptstyle \\theta \_ { i } = \\theta \_ { K y...

```

Не критично, но снижает чистоту IR.



\*\*Фикс:\*\* подавлять formula-регионы, чей bbox \*\*полностью внутри\*\* bbox table-региона.



\### 4. Ложное срабатывание figure на формуле (низкий приоритет)



\*\*Стр. 25\*\* — `figure\_00` содержит формулу `\\begin{array}{rl} \\cdots^{mm \\times n...`, а не рисунок. При этом сам детектор формул эту же область классифицировал как `formula\_00` — \*\*оба типа на одной области\*\*.



\*\*Фикс:\*\* отвергать figure-регионы, где `span\_math\_heuristic` даёт высокий score, или где площадь < порога.
