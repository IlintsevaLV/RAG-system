Примечание
Этот элемент используется для подробного описания изменения. Несколько
reasonForUpdate экземпляров этого элемента в одном экземпляре < >
для записи отдельных изменений, внесенных в модуль данных, не
используются. В проекте можно принять решение о постоянстве
формулировок этих подробных описаний.
Принятие решения о правиле выполнения проекта BRDP-S1-00089 -
Использование стандартных формулировок причин обновления:
Решение об использовании стандартного текста для причин обновления. Причина 
обновления может использоваться для автоматического генерирования модуля
данных изменений. Обычно в проектах принимается такое решение, начиная с
002 издания " " и выше. Например:
• Переработано с включением модификации XYZ
• Удалено. Модуль данных больше не требуется
