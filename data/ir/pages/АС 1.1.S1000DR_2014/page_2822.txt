2.2 Эксплуатация наземных/морских Объектов (последовательность
операций)
2.2.1 Предварительные требования
Предварительные требования κ модулям данных карт проверки должны содержать
все сведения, необходимые для подготовки последовательных операций для ввода
наземного/морского Объекта β действие, эксплуатации η при остановке работы
указанного наземного/морского Объекта. Описание последовательных операций
должно быть выполнено β виде пошаговой процедуры по форме контрольной карты.
Оно также должно включать все предварительные требования β виде описания или
ссылки на соответствующие модули данных.
Условия η правила техники безопасности должны входить β модули данных или быть
включены β качестве ссылки на соответствующий модуль данных.
Коды модулей данных должны иметь следующую структуру:
YY-Y-15-36-YY-YYY-YYYY-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Α15-36-YYYY-YYYYY-YYYY-Α (37 символов)
2.2.2 Ввод β действие
Модули данных карт проверки при вводе β действие должны включать все
необходимые сведения для последовательного ввода Объекта β действие. Описание
последовательного ввода β действие должно быть выполнено β виде пошаговой
процедуры по форме контрольной карты.
Коды модулей данных должны иметь следующую структуру:
YY-Y-15-37-YY-YYY-125Y-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Α15-37-YYYY-YYYYY-125Y-Α (37 символов)
2.2.3 Операции во время эксплуатации
Модули данных карт проверки во время эксплуатации должны включать все
сведения, необходимые для выполнения последовательных операций σ Объектом.
Описание последовательных операций должно быть выполнено β виде пошаговой
