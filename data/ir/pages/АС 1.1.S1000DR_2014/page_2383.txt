2.9 Вспомогательные модули данных, используемые для локализации
неисправности
Вспомогательные модули данных, используемые для локализации неисправности,
создаются только при крайней необходимости. По возможности следует использовать
уже имеющиеся модули данных (например, блок-схемы, монтажные схемы, схемы
общего расположения, планы доступа).
Коды модулей данных должны иметь следующую структуру:
YY-Y-SS-YY-00-NNY-430Y-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-YSS-YY-0000-NNYYY-430Y-Α (37 символов)
2.10 Таблица кодов неисправности
Таблица кодов неисправности (см. Табл. 2) - это упорядоченный нумерованный
перечень всех кодов неисправностей для применимой системы. Для каждого кода
неисправности дается одна или несколько ссылок на модули данных (коды модулей
данных) σ процедурами локализации неисправностей.
Индекс кода неисправности должен содержать:
код неисправности 
описание неисправности 
сообщения от встроенной системы контроля 
ссылка на модуль данных локализации неисправности 
Коды модулей данных должны иметь следующую структуру:
YY-Y-SS-YY-00-NNY-441Y-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-YSS-YY-0000-NNYYY-441Y-Α (37 символов)
