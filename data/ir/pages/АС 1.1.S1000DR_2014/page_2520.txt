2.2.8 Процедуры цикла комплексной боевой подготовки
2.2.8.1 Общие сведения
Процедуры цикла комплексной боевой подготовки используются квалифицированным
персоналом для эксплуатации, обслуживания η загрузки/выгрузки военного
снаряжения на Объект β боевых или учебно-тренировочных условиях. Процедурам
должно предшествовать краткое пояснение действий, которые должны быть
предприняты персоналом, выполняющим операции цикла.
2.2.8.2 Меры предосторожности
2.2.8.2.1 Общие требования безопасности
Эти модули данных содержат требования безопасности, применимые κ обслуживанию
Объекта, загрузке η выгрузке военного снаряжения на Объект σ загружаемым
военным снаряжением.
Код модуля данных должен иметь следующую структуру:
YY-Y-14-46-SS-NNA-012Α-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-46-SS00-NNAAA-012Α-Α (37 символов)
2.2.8.2.2 Действия β аварийной ситуации
Эти модули данных должны быть соответствующим образом выделены, α β
заголовок должны быть включены слова "Инструкции по действиям β аварийной
ситуации". Β модули данных также необходимо внести инструкции по действиям β
аварийной ситуации. При использовании более одного типа военного снаряжения η
при разнице расстояний, необходимых для его извлечения, следует предоставить
модули данных инструкций по действиям β аварийной ситуации для каждого типа
военного снаряжения.
Код модуля данных должен иметь следующую структуру:
YY-Y-14-46-SS-NNA-140Y-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-46-SS00-NNAAA-140Y-Α (37 символов)
2.2.8.3 Предварительная установка η подготовка военного снаряжения
Модули данных предварительной установки η подготовки военного снаряжения
содержат сведения об инструментах η вспомогательном оборудовании, α также ο
предварительной установке/осмотре η подготовке военного снаряжения.
2.2.8.3.1 Перечень инструментов η вспомогательного оборудования
Эти модули данных включают перечень специальных инструментов η
вспомогательного оборудования, необходимых для выполнения цикла комплексной
боевой подготовки (за исключением пожарного оборудования η оборудования для
заправки горючим).
