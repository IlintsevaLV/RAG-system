Сначала нужно определить общий тип условия. 
Затем для этого типа необходимо указать специальное условие. 
Например, можно определить тип "универсальный сервисный бюллетень" с
допустимыми значениями "до" и "после", а затем можно определить специальное
условие сервисного бюллетеня, проверяющее, был ли установлен кожух над цепью
(после) или не был (до). Можно определять множество специальных условий с
одним общим типом условия.
2.2.1 Определение перечня типов условий
Определение типа условия в модуле данных CCT включает обязательный
уникальный идентификатор, имя, описание и тип данных, а также необязательный
шаблон, перечисление, ссылки и интерактивные подсказки для пользователя.
Уникальный идентификатор используется для указания ссылок на данный тип
условия при определении специального условия.
Имя и описание облегчают идентификацию типа условия.
Тип данных указывает, содержит ли атрибут объекта логическое, строковое (по
умолчанию), целочисленное или вещественное значение.
Перечисление и шаблон вместе определяют допустимые значения для типа условия.
Подсказки состоят из вводимых вручную предложений, которые используются для
формирования интерактивного диалога для получения значения атрибута от
пользователя, когда такое значение не указано в модуле данных PCT. Поскольку
условия могут быть связаны с условиями окружающей среды, значение для данного
условия может оказаться известным только в момент проведения процедуры
технического обслуживания. Пример подсказки: “SB 002 (требует включения SB
001)”.
Определение типа условия аналогично определению атрибута объекта и выполняется
в соответствии с теми же правилами с тем исключением, что у типа условия нет
отображаемого имени. См. Глава 4.14.1 .
2.2.2 Определение перечня условий
Существует два типа определения условий:
cond Внутреннее определение с использованием элемента < > 
externalCond Внешнее определение с использованием элемента < > 
2.2.2.1 Внутреннее определение
Определение условия в модуле данных CCT включает обязательный уникальный
идентификатор, ссылку на тип условия, имя и описание, а также необязательное
отображаемое имя и ссылки. Уникальный идентификатор используется для указания
ссылок на это условие из других модулей данных и из перечня включенных
элементов этого модуля данных. Имя и описание облегчают идентификацию условия.
Отображаемое имя можно использовать при создании части комментария по
применимости, предназначенной для человека. См. Глава 7.8 . Ссылки используются,
если с этим условием связаны дополнительные данные. Часто с их помощью
указывают на документацию сервисного бюллетеня в соответствующем условии.
