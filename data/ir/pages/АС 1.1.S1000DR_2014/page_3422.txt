2.3.3 Унифицированные характеристики ресурсов
Унифицированные характеристики ресурсов (URC) определяют простую структуру
метаданных β виде пар "имя/значение". Имя URC является именем элемента
метаданных, α значение URC соответствует данным внутри этого элемента
метаданных для определенного ресурса. Документы возвращают имя URC β виде
имени тега XML η значение URC β виде текстовой строки или подобъекта внутри
данного тега. Для выполнения запросов поиска параметры запроса могут
сопоставляться σ данными внутри средства поиска. Эта простая структура хорошо
подходит для НТТР-запросов, которые также описываются посредством пар
"имя/значение". URC должна подходить для большинства нужд идентификации
метаданных. Более усовершенствованное описание ресурсов может быть основано
на схемах RDF. Рекомендуется, чтобы имена URC обрабатывались как
неучитывающие регистр без включения префикса пространства имен.
Β следующем примере показана URC σ именем "Title" (Наименование) η значением
"Example Resource Title" (Пример наименования ресурса), β которой используется
схема ресурсов "Дублинского ядра".
<dc:title>Example Resource Title</dc:title>
