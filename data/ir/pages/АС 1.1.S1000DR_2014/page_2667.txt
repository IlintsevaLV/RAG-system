2.5.4 Продолжительность задачи
Должно быть указано время, требуемое для выполнения задачи проверки.
2.6 Специальные проверки
Включаются события, по результатам которых проводятся специальные проверки
(например, жесткая посадка, внезапная остановка двигателя, превышение скорости).
Данные проверки группируются по соответствующим участкам летательного аппарата.
Включается чертеж летательного аппарата или приспособления, показывающий
последовательность проверки участка. Описание участка должно включать все
поверхности, материалы, компоненты η оборудование, относящиеся κ указанному
расположению. Обязательны κ использованию η могут быть представлены β
табличной форме следующие поля данных проверки.
2.6.1 Зона
Поле "Зона" включает название η номер участка.
2.6.2 Номер позиции
Указывается порядковый номер проверки.
2.6.3 Временной интервал
Указывается назначенный интервал проведения проверки (позволяет создавать
столбцы σ временем проведения проверок).
2.6.4 Единица оборудования
Сведения, определяющие изделие, требующее проверки, формулируются минимально
возможным количеством слов.
2.6.5 Процедура проверки
Описываются все процедуры, необходимые для проведения каждой проверки. Когда
конкретная операция не требует проведения во время каждой проверки, β процедуре
должен быть задан временной интервал/частота проведения операции (например,
"Производить только при проведении каждой второй проверки").
