1 Общие сведения
Принципы демонтажа базируются на одном основном принципе η трех правилах.
2 Принципы демонтажа
2.1 Основной принцип
Принцип демонтажа основан на последовательной нумерации сборочных единиц,
производимой во время демонтажа оборудования η последующих операций по
техническому обслуживанию. Пронумерованные сборочные единицы должны быть
снабжены своим комплектом модулей данных. Обозначение "00" резервируется для
оборудования β сборе, затем следует последовательная нумерация β соответствии σ
правилами, описанными β данной главе.
Примечание
Последовательность нумерации не обязательно должна линейно соответствовать
какой-либо пошаговой задаче технического обслуживания.
2.2 Правила нумерации сборочных единиц
Сборочные единицы должны быть нумерованы при помощи кода демонтажа, если
выполняется как минимум одно из нижеследующих условий:
2.2.1 Правило №1
Первое условие нумерации сборочной единицы при помощи кода демонтажа -
выполнение дальнейшего технического обслуживания на данной сборочной единице.
Если для данной сборочной единицы не предусмотрены операции технического
обслуживания, номер или комплект модулей данных не назначается.
2.2.2 Правило №2
Вторым условием назначения номера при помощи кода демонтажа является
сложность сборочной единицы. Простые сборочные единицы не требуют специальных
модулей данных. Это правило используется для предотвращения излишнего
дробления сведений ο техническом обслуживании.
2.2.3 Правило №3
Кроме двух первых правил η для предотвращения излишне детальной
классификации нумерация при помощи кода демонтажа производится только β том
случае, если объем сведений об операциях технического обслуживания является
достаточным для подготовки отдельного модуля данных.
2.3 Сборочные единицы η детали
Как правило, после демонтажа сборочной единицы образуются отдельные детали.
Поскольку иногда операции по техническому обслуживанию применяются для деталей
