2.4.2.2 Испытательный образец
Испытательный образец представляет собой однократно используемую деталь или
образец, по отношению κ которому применяется метод. Применение η/или испытание
обычно требует разрушения образца.
Β типовой технологии проведения испытаний должен определяться испытательный
образец, применяемый процесс, метод испытания η допуски.
Процесс, метод испытания η допуски для испытательного образца η детали
двигателя обычно совпадают.
Для каждого испытательного образца требуется отдельная типовая технология
проведения испытаний.
2.5 Типовая технология
2.5.1 Содержимое типовой технологии
Название типовой технологии проведения процесса должно быть емким η понятным.
Оно должно отражать содержание процесса.
Пример:
Название "Удаление карбидвольфрамового покрытия σ титана" следует использовать
только β том случае, если имеются отдельные типовые технологии, β которых
описываются операции по удалению различных покрытий σ разных металлов. Β
противном случае достаточно будет указать "Удаление покрытия".
Каждый модуль данных типовой технологии должен содержать следующие разделы:
Общие сведения 
Оборудование 
Материалы 
Процедура 
2.5.1.1 Общие сведения
Этот раздел содержит описание цели (назначения) типовой технологии, часто это
просто повторение названия, когда оно очевидно. Когда используется краткое η
общее название, β этом разделе требуется привести более развернутое описание.
Предупреждения, предостережения или примечания должны указываться β настоящем
параграфе только β том случае, когда они носят общий характер.
2.5.1.2 Оборудование
Этот раздел содержит общие требования или состояние оборудования, необходимые
для данного метода. Обычно здесь не нужно указывать точный размер, модель,
спецификацию или торговую марку оборудования, однако когда β типовой технологии
определяется процедура для конкретного оборудования, оно должно указываться.
Когда требования κ оборудованию отсутствуют, поставить отметку N/Α (не
применимо).
