2.4.2 Странично-ориентированные публикации по схеме электрооборудования
Для странично-ориентированных публикаций по схеме электрооборудования сведения
для представления созданных данных, например, перечней проводов жгутов,
перечней соединений, создаются на базе исходных данных, как описано выше, на
предварительном этапе. Результаты предварительного этапа хранятся β модулях
данных.
Модули данных должны подготавливаться на основании описательной Схемы. Эти
модули данных должны иметь следующую структуру:
YY-Y-YY-YY-YY-NNA- XXX Α-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-YYY-YY-YYYY-NNAAA- XXX Α-Α (37 символов)
где
" XXX " обозначает информационный код, который обозначает следующие технические
сведения:
031 = Данные стандартных деталей электрооборудования 
056 = Перечни оборудования 
057 = Перечни проводов 
058 = Перечни жгутов 
Β варианте информационного кода используются буквы " Α ", " Β "….." Z ", когда
требуется более одного типа перечня из представленных β Разд. 2.4.2.1-Разд. 2.4.2.3.
Явное кодирование модулей данных странично-ориентированных публикаций по
схеме электрооборудования, относящихся κ системе, подсистеме η β некоторых
случаях κ подподсистеме, отличается для воздушных, наземных η морских систем.
Оно основано на стандартной системе нумерации для Объекта. Управляемые
стандартные системы нумерации приведены β Глава 8.2 .
Модули данных странично-ориентированных публикаций по схеме
электрооборудования для летательных аппаратов, двигателей η оборудования должны
иметь следующую структуру кода:
YY-Α-91-YY-00-NNA- XXX Α-Α (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y91-YY-0000-NNAAA- XXX Α-Α (37 символов)
