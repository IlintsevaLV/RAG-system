2.4 Профиль формата TIFF β спецификации Σ1000Δ
2.4.1 Общие сведения
Для двоичной растровой графики β теговом формате файлов изображений (TIFF)
должен использоваться алгоритм сжатия CCITT группы 4. Для цветной растровой
графики β теговом формате файлов изображений (TIFF) должен использоваться
метод сжатия Лемпела-Зева-Уолша (LZW) без потери данных, описанный β
спецификации Adobe TIFF 6.0 .
Σ1000Δ запрещает использование нескольких изображений β одном TIFF-файле.
Допускаются разрешения (плотность β пикселях) 300, 400, 600 η 1200 пикселей на
дюйм (ppi) σ минимальным разрешением 300 ppi.
2.4.2 Сведения по профилю
Профиль приложения Σ1000Δ для файлов формата TIFF определен как производный
профиль, основанный на спецификации формата Adobe TIFF 6.0. Далее приведены
подробные сведения по профилю, но только для тех положений, β которых он
отличается от спецификации формата TIFF.
