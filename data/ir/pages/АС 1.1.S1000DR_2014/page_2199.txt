4 Кодирование модуля данных общего информационного
репозитория
Модули данных CIR кодируются так же, как и другие модули данных. См. Глава 4.3 .
За каждым типом модуля данных общего информационного репозитория закреплен
конкретный информационный код. Определения информационных кодов см. в Глава
8.4 .
Для каждого типа репозитория CIR рекомендуется иметь только один модуль данных
в во всем Проекте (или по крайней мере для одного идентификационного кода
модели). При использовании нескольких модулей данных для определенного типа
модуля данных CIR их структуризация определяется применяемой системой
нумерации (SNS). См. Глава 4.3.3 .
Использование одного модуля данных CIR для Объекта означает, что этот модуль
данных CIR действителен для всего пакета публикации или всей базы данных CSDB.
Для такого типа реализации рекомендуется использовать SNS 00-00-00.
Ср. пример кода модуля данных для модуля данных CIR деталей, когда
используется только один модуль данных CIR деталей (SNS: D00-00-00):
DMC-S1000DLIGHTING-AAA-D00-00-00-00AA- 00G A-D
Здесь «00G» —- это информационный код для модуля данных CIR деталей
