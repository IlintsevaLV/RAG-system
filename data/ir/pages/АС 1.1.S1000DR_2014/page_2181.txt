S1000DR-UACRU-01000-00
dmNode dialog нескольких элементов < >, включающих элемент < >, два элемента
dmRef proceduralStep < > и два элемента < >. Пользователь взаимодействует с
логическим ядром посредством функций навигации ("Далее" и "Назад"), которые дают
логическому ядру команду на продолжение или возврат, и функций диалога, которые
собирают данные о состоянии. Подробности см. в Глава 3.9.5.2.10 .
Архитектура, представленная на Рис. 1, предполагает, что логическое ядро и ИЭТП
являются отдельными компонентами. Данная архитектура используется только с
целью иллюстрации и не является обязательной в спецификации S1000D. Такую же
функциональность могли бы обеспечить многие подобные архитектуры.
Типичная последовательность операций обычно включает в себя следующие.
1 Логическое ядро запускает выполнение процессного модуля данных.
dmNode Выполняется элемент < >.
Логическое ядро посылает в ИЭТП фрагмент диалога для показа пользователю.
2 Пользователь отвечает на вопрос(ы) диалога в ИЭТП.
ИЭТП посылает ответ пользователя логическому ядру.
Логическое ядро обновляет соответствующую переменную в таблице состояний.
dmIf 3 Выполняется элемент < >.
Логическое ядро оценивает выражение (IF) относительно переменных из таблицы
состояний.
Логическое ядро определяет путь для продолжения.
dmThenSeq 4 Предположим, это ветвь элемента < >:
dmNodeAlts 4.1 Выполняется элемент < >.
dmNode Вычисляется выражение применимости для каждого элемента < > в
dmNodeAlts элементе < > с использованием переменных из таблицы
состояний.
dmNode Выполняется первый элемент < >, выражение применимости которого
равно TRUE (истина).
dmNode dmRef 4.2 Выполняется элемент < > (содержащий элемент < >).
Логическое ядро уведомляет ИЭТП о необходимости показать модуль
данных, на который указывает ссылка.
ИЭТП находит нужный модуль данных и показывает его пользователю.
dmElseSeq 5 Предположим, это ветвь элемента < >:
dmNode 5.1 Выполняется элемент < > (proceduralStep).
proceduralStep Логическое ядро посылает в ИЭТП фрагмент диалога < >
для показа пользователю.
5.2 Пользователь использует функцию "Далее" в ИЭТП.
ИЭТП уведомляет логическое ядро о необходимости перейти к следующему
элементу.
dmNode 5.3 Выполняется второй элемент < > (proceduralStep).
proceduralStep Логическое ядро посылает в ИЭТП фрагмент диалога < >
