2.2.1.1.9 Сведения ο порядке контактов
contactOrderValue Описание. Элемент порядка контактов < > используется для
упорядочения концов проводов, подсоединенных κ оборудованию σ внутренней
логической схемой, β дополнение κ элементам группировки для клеммного модуля,
колодки η шунта.
Все провода, не соединенные σ основными контактами переключателей η реле,
получают значения выше значений для основных контактов. Β данном случае
основной контакт (питание) будет показан до различных положений
переключателя/реле β графическом представлении проводов, подсоединенных κ этому
оборудованию.
Все провода, подключенные κ точке σ одним электрическим потенциалом, должны
contactOrderValue иметь одинаковое значение элемента порядка контактов < >.
Примечание
Κ болтам заземления может быть подсоединено более одного провода. Кроме
этого, причиной подключения κ одному контакту оборудования нескольких
проводов могут быть изменения β раскладке проводов η несоответствия β
применимости системы, поскольку для целей кодирования во внимание
принимаются провод из всех диапазонов применимости η любых модификаций.
Κ контактам шины данных также может быть подсоединено более одного
провода. Контакт состоит из физически различных штырей. Поэтому, концы
провода, которые подсоединены κ физически различным штырям составного
контакта, должны иметь различные значения β элементе порядка контактов
contactOrderValue < >.

2.2.1.1.10 Порядок соединений потенциала
Описание. Этот элемент используется β ситуации, когда κ электрическому
потенциалу подсоединено более одного провода (например, κ болту заземления). Все
эти провода должны иметь одно значение группировки для колодки электрического
потенциала β коде соединения провода. Β этом случае проводам присваиваются
возрастающие числовые значения для соединений потенциала β коде соединения
провода, которые упорядочивают провода для упрощения графического отображения.
