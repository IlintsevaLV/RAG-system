Обработка возвращения значений по имени:
Для обработки возвращаемых значений по имени внешнее приложение должно
предоставить возвращаемые данные β виде пар "имя/значение", которые логическое
ядро может использовать для соотнесения имен со значениями.
Используя возвращение значений по имени, логическое ядро будет брать пары
"имя/значение" из внешнего приложения η соотносить их σ переменными, указанными
β разметке получения по имени (строки 17-24), согласно обозначению имени,
returnedValueName указанному β элементе < >. Необходимо заметить, что β
этом примере сохраняются только два из трех возвращаемых значений η они
перечислены β разметке β обратном порядке, относительно того, β каком они были
получены из внешнего приложения.
Β данном примере после возвращения данных инструментом локализации
неисправностей провода переменные таблицы состояний будут изменены на
следующие значения:
RtnWireno = "Α1000Α26" 

2.5.3 Операция отмены внешнего приложения
Приведенный пример показывает, как можно структурировать данные для
обеспечения устойчивости κ ошибкам при взаимодействия σ внешним приложением.
Β приведенном примере предполагается, что испытанию подвергается деталь
оборудования, при этом испытание может проводиться автоматически или вручную.
При автоматическом методе существует вероятность возникновения ошибки, при
которой ожидаемые результаты не будут возвращены. ИЭТП/логическое ядро будет,
по умолчанию, бесконечно ожидать возвращаемого значения.
