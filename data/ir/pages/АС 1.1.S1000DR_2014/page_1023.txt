2.2.1.1.11 Код анализа сети
Описание. Код анализа сети описывает характеристики конца провода β анализе
сетевых соединений β отношении κ другим проводам оборудования. Элемент основан
на характеристиках оборудования, κ которому подсоединяется конец провода. Этот
элемент может быть использован β качестве основного для анализа электрических
соединений β системе.
Код анализа сети используется для анализа электрических соединений β системе η
представляет собой двузначное число. Он определяет для каждого конца провода,
является ли он исходной точкой, конечной точкой анализа соединения, либо анализ
продолжается через соединения оборудования (например, соединители,
переключатели η τ. δ.).
Значения, приведенные β Табл. 3, являются рекомендованными.
Таблица 3 Коды анализа сети
Значение Смысл для анализа соединения
01 Исходная η конечная точки анализа соединения
02 Исходная точка, продолжение анализа через разъемное соединение
(точка перехода)
03 Исходная точка, продолжение анализа через соединение оборудования σ

06 Исходная точка отсутствует, анализ продолжается на том же
