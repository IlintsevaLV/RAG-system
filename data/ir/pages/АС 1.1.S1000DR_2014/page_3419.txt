2.2 Определение интерфейса поиска ресурсов
Интерфейс может поддерживать следующие функции, определенные стандартом RFC
2483. Для простоты интерфейса необходимо, чтобы одна служба выполняла
различные функции. Выбор вызываемой функции основывается на структуре η
вхождении параметров НТТР-запроса, отправляемых β службу поиска.
N2R/Λ2R: URN/URL для поиска ресурса 
N2C/Λ2C: URN/URL для поиска характеристики 
N2Λ/Λ2N: поиск URN по URL 
NEN/LEL: эквивалентность URN/URL 
2.2.1 URN/URL для поиска ресурса (N2R/Λ2R)
Данная функция находит ресурс по URN или URL. Она является основной службой
интерфейса, позволяющей вернуть данные ресурса по ссылке, содержащей URN.
Служба принимает URN β качестве параметра запроса η возвращает данные
ресурса. Если ресурс не известен службе, она вернет сообщение об ошибке 004
"Unknown Resource" (Неизвестный ресурс) или перенаправит κ ресурсу через HTTP-
запрос. Если ресурс может быть возвращен β нескольких форматах, например, на
разных языках, служба предоставляет один, который считается ресурсом по
умолчанию, или ресурс, наиболее подробно определенный посредством
дополнительных параметров.
urn Формат запроса : зарезервированным параметром запроса η значением
urn параметра должна являться строка URN. Если найден только параметр или
найдены только другие параметры со значениями, происходит поиск N2R. Если β
службу передан параметр без значения η имя параметра можно интерпретировать
как URN, тогда ресурс для поиска будет ресурсом, указанным β имени параметра.
 url Λ2R выполняет ту же функцию, но принимает URL-адрес β параметре .
Пример запроса ресурса, определенного на английском языке (при возможности):
http://urn.server.com/urnService?urn=URN:NID:NSS&lang=EN
либо
http://urn.server.com/urnService?URN:NID:NSS&lang=EN
