Рис. 3 Пример навигационной панели
Пиктограммы должны символизировать функцию, которую они выполняют. Значение
пиктограмм должно быть очевидно для пользователя. Использование пиктограмм не
является обязательным, их окончательный набор определяется на основе требований
конечного пользователя и среды эксплуатации. Пиктограммы соотносятся с базовыми
функциями, описанными ранее в этой главе, и включают дополнительные значки для
возможного расширения функциональности приложения.
При выборе функции в виде дочерних элементов могут появляться каскадные меню.
В раскрывающемся меню дочерние элементы появляются рядом с выбранной
функцией. Может быть несколько уровней каскадных меню.
Функции, которые остаются неактивными во всех представлениях, должны
отключаться. Панель должна оставаться доступной.

панели главного меню:

2.4.2.1 Назад
Данная функция осуществляет навигацию по данным путем последовательного
возврата к предыдущим представлениям.
2.4.2.2 Далее
Данная функция осуществляет навигацию по данным путем последовательного
перехода к следующим элементам.
2.4.2.3 Содержание
Данная функция включает и выключает панель содержания. См. Разд. 2.3.4.
2.4.2.4 Журнал
Данная навигационная функция отображает последовательность ранее просмотренных
данных, например, открывавшийся модуль данных.
2.4.2.5 Поиск
Данная функция открывает диалоговое окно поиска.
2.4.2.6 Печать
Данная функция позволяет выполнять печать с помощью диалогового окна печати.
Если данные имеют ограниченный доступ, то функция печати может быть
деактивирована, а кнопка печати будет иметь серый цвет (недоступна для нажатия).
