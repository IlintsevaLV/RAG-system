2.1.2.1 Внутреннее определение
Определение атрибута объекта в модуле данных ACT включает обязательный
уникальный идентификатор, имя и описание, а также необязательное отображаемое
имя, флаг идентификатора объекта, тип данных, перечисление, шаблон и подсказки
для пользователя.
Уникальный идентификатор используется для отсылки к этому атрибуту объекта из
других модулей данных. Имя и описание облегчают идентификацию атрибута
объекта,
Атрибут объекта при необходимости может указываться в виде идентификатора
объекта. Такой специально обозначенный атрибут объекта (например, серийный
номер) может использоваться для уникальной идентификации конкретного экземпляра
Объекта. Атрибут объекта может указываться как "основной" или "вспомогательный"
идентификатор объекта. "Основной" используется для указания предпочтительности
использования данного атрибута при выборе конкретного экземпляра объекта. Если
атрибут объекта определен как "основной" идентификатор объекта, он должен быть
включен в таблицу перекрестных ссылок на объекты для экземпляра объекта.
"Вспомогательный" используется для указания вспомогательных ключевых слов для
определения конкретного экземпляра объекта. Если атрибут объекта определен как
вспомогательный идентификатор объекта, он может быть включен в описание
объекта в таблице перекрестных ссылок на объекты, но это не является строгим
требованием. См. Глава 3.9.5.3.1 .
Отображаемое имя можно использовать при создании части комментария по
применимости, предназначенной для человека. См. Глава 7.8 .
Тип данных указывает, содержит ли атрибут объекта логическое, строковое (по
умолчанию), целочисленное или вещественное значение. Перечисление и шаблон
вместе определяют допустимые значения для атрибута объекта.
Допустимые значения для атрибута объекта ограничиваются типом данных.
Допустимые значения для атрибута объекта могут также задаваться с помощью
перечисления, шаблона или с использованием комбинации этих средств. Шаблон
задает формат, которому должны соответствовать значения. Например, серийный
номер должен состоять из трех цифр или версия велосипеда представляет собой
сочетание префикса Mk, за которым следует цифра 1 или 9. Перечисление задает
определенное количество отдельных допустимых значений или диапазонов.
Например, модель велосипеда должна быть "Brook trekker" или "Mountain storm",
серийный номер должен быть числом от "1" до "999" либо версия велосипеда
должна быть одним из двух значений: "Mk1" или "Mk9". В этих двух методах есть
схожие возможности, но и есть уникальные. Примеры из этого параграфа находятся
в образце модуля данных по велосипедам DMC-S1000DBIKE-AAA-D00-00-00-
00AA-00WA-D.
Атрибут объекта не может содержать зарезервированные символы тильды (~) и
вертикальной черты (|).
Подсказки состоят из вводимых вручную предложений, которые используются для
формирования интерактивного диалога для получения значения атрибута от
пользователя, когда такое значение не указано в модуле данных PCT. Они
используются, когда простого автоматического формирования диалога с
отображаемым именем недостаточно. Пример подсказки: "Серийный номер (находится
под нижним кронштейном на стыке двух кривошипов педали)"
