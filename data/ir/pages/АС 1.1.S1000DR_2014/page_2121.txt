2.1.1.1.1 Расширение идентификатора
identExtension Описание. Элемент < > предлагает дополнительные параметры
для уникальной идентификации модуля публикации β тех случаях, когда кода модуля
публикации, номеров издания η рабочей версии вместе σ обозначениями языка η
страны оказывается недостаточно для глобальной уникальной идентификации. Этот
элемент задает уникальную категорию производителя для идентификации.
identExtension Элемент разметки: < > (O)
Атрибуты:
extensionProducer (Μ), изготовитель модуля публикации, значение которого 
образует часть глобально уникального идентификатора экземпляра модуля
публикации η содержит CAGE-код изготовителя экземпляра модуля данных.
exensionCode (Μ), расширенный код модуля публикации, значение которого 
задается изготовителем модуля публикации. Обычно, но необязательно, он
содержит данные, связанные σ заказчиком, например, CAGE-код заказчика,
дополненный порядковым номером. При использовании он должен содержать
прописные буквенные символы (Α-Z) η цифры (0-9)
Дочерние элементы:
Нет 
Пример разметки:

extensionProducer="Σ1000Δ"/>
