2.2.5.2.1 Подготовка военного снаряжения
Эти модули данных включают процедуры, необходимые для проверки и подготовки
каждой единицы военного снаряжения, включая любой применимый компонент. Они
также должны включать процедуры, необходимые для сборки и установки
назначенных взрывателей до загрузки военного снаряжения. Необходимо также
включить процедуры для проверки безопасности каждой единицы военного
снаряжения с взрывателем. Контекст всех шагов является единичным.
2.2.5.2.2 Установка зарядов перед загрузкой
Эти модули данных включают процедуры, необходимые для установки зарядов в те
компоненты, в которых перед загрузкой военного снаряжения должны содержаться
пиропатроны.
Требуется выполнить следующее:
1 Провести необходимые проверки без подачи питания.
2 Выполнить необходимую проверку пиропатронов на работоспособность.
3 Установить пиропатроны.
Контекст всех шагов является комплексным.
2.2.5.2.3 Загрузка
Эти модули данных включают процедуры, необходимые для загрузки военного
снаряжения. Контекст всех шагов является единичным.
2.2.5.2.4 Взрыватели
Эти модули данных включают процедуры, необходимые для проверки военного
снаряжения с предварительно установленными взрывателями, а также для
непосредственной установки взрывателей, которые нельзя устанавливать до загрузки
военного снаряжения. Контекст всех шагов является единичным.
2.2.5.2.5 Операции после загрузки
Эти модули данных включают процедуры, необходимые для обеспечения
безопасности и электрической совместимости военного снаряжения и его
приспособлений. Контекст всех шагов должен быть комплексным.
2.2.5.2.6 Установка заряда после загрузки
Эти модули данных включают процедуры, необходимые для зарядов, которые
устанавливаются только после загрузки военного снаряжения. Требуется выполнить
следующее:
1 Провести необходимые проверки без подачи питания.
2 Выполнить необходимую проверку пиропатронов на работоспособность.
3 Установить пиропатроны.
Контекст всех шагов является комплексным.
