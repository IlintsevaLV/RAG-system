2.4.3 Монтаж силовой установки
Приспособления и системы должны устанавливаться в логическом порядке
последовательности монтажа. Установка последовательной группы может включать
установку одного или нескольких приспособлений на участке монтажа, если способ
установки требует монтажа всей системы целиком.
На иллюстрациях должны быть представлены приспособления, трубопровод,
компоненты и связанное оборудование в смонтированном виде. Для лучшего
понимания затрагиваемые детали силовой установки должны выделяться линиями
различной толщины. При необходимости следует включать виды узлов для
покомпонентного представления фитингов, уплотнений и других деталей, которые не
показаны на виде собранного узла. Порядковые номера, присвоенные деталям в
покомпонентной схеме, должны соответствовать номерам позиций, указанных на
последующих страницах с перечнем деталей. Чертеж расположения компонента
должен даваться в верхней части каждой иллюстрации для указания местоположения
узла. Информация по техническому обслуживанию по монтажу силовой установки
должна подготавливаться по тому же образцу, который используется для процедур
по монтажу приспособлений. Установка монтажно-установочного узла, собранного в
соответствии со сведениями в модулях данных по сборке приспособлений, должна
указываться в модулях данных по монтажу силовой установки. Эти узлы должны
указываться в модулях данных по монтажу силовой установки путем ссылки на
соответствующий номер модуля данных и (при наличии) на обозначение
устанавливаемой детали, как указано в модулях данных по монтажу приспособлений.
См. Рис. 5.
Коды модулей данных должны иметь следующую структуру:
YY-Y-71-00-02-NNA-710Y-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y71-00-0200-NNAAA-710Y-A (37 символов),
где "NN" в коде демонтажа является порядковым номером, начинающимся с "00",
если требуется более одного модуля данных.
Действительно: Все S1000D-A-05-02-0205-00A-040A-A
