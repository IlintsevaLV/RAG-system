Функционирование интерактивной публикации по схеме электрооборудования, как
описано в Разд. 2.5, возможно, только если используется схема
электрооборудования.
1.3.1 Схема данных по электрооборудованию
Схема данных по электрооборудованию используется для хранения информации по
электрооборудованию, такой как данные проводов, данные жгутов, сведения об
электрическом оборудовании и стандартным электрическим компонентам.
1.3.2 Схема описания данных по электрооборудованию
Для каждого существенного элемента схемы данных по электрооборудованию
требуется описание поля элемента. Схема описания данных по электрооборудованию
регламентирует конфигурацию и использование всех элементов данных схемы
данных по электрооборудованию в проекте или организации.
Описание поля элемента может использоваться в интерактивной публикации по
схеме электрооборудования в качестве краткой сводки или для настройки и
компоновки элементов в публикации в соответствии со специальными соглашениями
об именовании в проекте или организации.
Схема описания данных по электрооборудованию описывает все существенные
элементы схемы данных по электрооборудованию с помощью следующих трех
элементов
fieldName < >, который содержит особые соглашения об именовании в проекте 
или организации
descr < >, который содержит дополнительное описание содержимого элемента, 
например, особые значения, определенные в проекте или организации
(например, цвет провода может быть только красным, желтым или зеленым).
refs < >, который содержит ссылки на другие модули данных или технические 
публикации со стандартами техническими данными и т. п.
Модуль данных описания данных по электрооборудованию должен быть основан на
схеме описания данных по электрооборудованию. Коды модулей данных должны
иметь следующую структуру:
YY-Y-YY-YY-00-00 Y -029A-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-YYY-YY-0000-00 YYY -029A-A (37 символов)
где " Y "-" YYY " в варианте кода демонтажа используются, если требуется более одного
модуля данных, например, для разных языков.
Явное кодирование модулей данных описания данных по электрооборудованию,
относящихся к системе, подсистеме и в некоторых случаях к подподсистеме,
отличается для воздушных, наземных и морских систем. Оно основано на
стандартной системе нумерации для Объекта. Управляемые стандартные системы
нумерации приведены в Глава 8.2 .
Модули данных описания данных по электрооборудованию для летательных
аппаратов, двигателей и оборудования кодируются следующим образом:
YY-Y-91-00-00-00Y-029A-A (17 символов)
Действительно: Все S1000D-A-05-02-0104-00A-040A-A
