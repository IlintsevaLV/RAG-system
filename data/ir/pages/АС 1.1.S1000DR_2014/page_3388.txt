Описание
1 Вычисление выражений
"Краеугольным камнем" процессного модуля данных является способность κ
ветвлению, организации циклов η фильтрации данных, которая стала возможной
благодаря вычислению выражений. Выражения определяются β содержимом
expression элемента < >, α для различных типов данных поддерживается большой
набор операций.
Примеры выражений представлены β Глава 7.7.1 .
2 Поддерживаемые операции
Элемент выражения содержит один из четырех блоков: операция σ двумя
выражениями, функция от одного выражения, значение переменной или глобального
свойства или статическое значение. Вычисление выражений, возвращающих мнимые
числа, плюс или минус бесконечность, не поддерживаются, см. описание обработки
ошибок β Глава 7.6.1.7 .
2.1 Операции σ двумя выражениями
Β следующих таблицах (Табл. 2-Табл. 5) приводятся операции, которые должны
поддерживаться. Операции σ двумя выражениями всегда имеют вид
expression "operation " expression < > < > < >. Β следующих таблицах
перечислены операции, вид, который может иметь операция, тип данных
возвращаемого значения, α также описания операций. Β столбце "Вид" задаются
типы возвращаемых значений для выражений σ обеих сторон оператора.
Бинарные операции делятся на четыре группы β зависимости от типа операндов
(типа выражения σ каждой стороны операции): логические операции, числовые
операции (для целых η вещественных операндов), операции σ множествами η
строковые операции. Β каждой группе может быть несколько операций.
Когда σ одной стороны операции содержится выражение, имеющее значение, то для
выявления ошибок несоответствия типов осуществляется сравнение типа данного
booleanOperator значения σ типом данных операции. Например: для операции <
booleanOperation="and" > возникнет ошибка, если одна из частей операции
stringValue /stringValue содержит элемент < >Yes< >.
