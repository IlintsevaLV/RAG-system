2.4.1.1 Объект для вставки
insertObject Описание. Элемент < > представляет один фрагмент модуля
данных, который был добавлен σ момента предыдущего издания модуля данных.
При получении нового издания модуля данных этот фрагмент необходимо вставить.
insertObject При использовании атрибутов < > можно указывать место, куда
нужно вставить новый объект. Рекомендуется использовать эти два атрибута.
Для заданного файла обновления данных можно использовать только объекты,
разрешенные для модуля данных. Например, файл обновления данных, связанный σ
partSpec модулем данных CIR деталей, должен содержать только элементы < >
для вставки. (Это правило применяется β модуле BREX по умолчанию).
