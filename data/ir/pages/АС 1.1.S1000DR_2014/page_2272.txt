2.1.2.4 Срок службы экземпляра объекта
По мере обслуживания экземпляров объекта в течение их срока службы
фактическая конфигурация экземпляра объекта также изменяется и поддерживается
в модуле данных PCT. Модуль данных PCT может публиковаться в случаях, когда
конфигурация экземпляра объекта относительно статична. Модуль данных PCT также
может быть промежуточным файлом, который используется в определенное время
только для передачи конфигурации экземпляра объекта между источником
разработки, например системой управления техническим обслуживанием, и средством
просмотра.
2.1.2.5 Фильтрация конечного представления
На финальной стадии использования средство просмотра использует конфигурацию
экземпляра объекта из модуля данных PCT в качестве фактических значений,
которые указываются в комментариях по применимости для вычисления результата.
Положительный результат означает, что связанные данные подходят для
отображения, отрицательный результат означает, что связанные данные для
отображения не подходят. Таким образом, отображение данных можно настраивать
под конкретный экземпляр объекта.

2.1.3 Компоненты комментария по применимости
Комментарий по применимости разделен на две части:
одна часть, предназначенная для человека; 
одна часть для машинной обработки. 
В проекте или организации необходимо решить, какая часть комментария по
применимости будет реализована в зависимости от требований.
В проекте или организации, где необходимо создавать печатные или статичные
электронные версии и не нужно поддерживать специализированные конечные
продукты, потребуется использовать только часть комментария по применимости,
предназначенную для человека. Часть комментария по применимости для машинной
обработки, а также модули данных ACT, CCT и PCT не требуются. Подробности
реализации см. в Глава 3.9.5.3 .
В проекте или организации, где нужно фильтровать конечное представление или
создавать специализированные конечные продукты, потребуется использовать часть
комментария по применимости для машинной обработки. Помимо этого, комментарии
по применимости также нужно будет представлять в понятном виде конечному
пользователю. Это можно сделать, определяя часть комментария по применимости,
предназначенную для человека, или реализовав в средстве просмотра функции
формирования понятных комментариев по применимости из машинного варианта во
время просмотра. В проекте или организации необходимо решить, определять ли
часть, предназначенную для человека, или использовать возможности средства
просмотра для формирования понятных комментариев по применимости.
