2.2 Работа с переменными состояния
Для выполнения контекстной фильтрации и определения последовательности
логическое ядро должен формировать, сохранять, извлекать, обновлять и удалять
данные о состоянии в таблице состояний. Дополнительные сведения об этих
операциях см. в Глава 7.6.1.3 .
Логическое ядро заполняет таблицу состояний, принимая утверждения из элементов
variablePreSets variablePostSets процессного модуля данных (< >, < >,
dialogs externalApplications assertions < >, < >, < >). Таблица состояния
- это просто совокупность переменных и их значений.
Логическое ядро использует данные о состоянии из таблицы состояний для
вычисления выражений, используемых в применимости, ветвлениях и циклах модуля
данных. Для вычисления выражения логическое ядро должно извлечь необходимые
данные из таблицы состояний. Если необходимые данные там не представлены,
логическое ядро должно запросить данные с помощью диалогов, которые могут быть
связаны с переменной при ее объявлении. Если используемая в выражении
переменная не имеет ни значения в таблице состояний, ни соответствующего
диалога (т. е. нет возможности получить значение), логическое ядро выдает сигнал
ошибки и останавливает обработку. Это считается неисправимой ошибкой (см. Глава
7.6.1.7 ).
