2.2 Альтернативные обозначения
altIdentGroup Описание. Β элементе < > содержится перечень альтернативных
обозначений идентификационной трубки, которые состоят из обозначения компонента,
присвоенного изготовителем, η соответствующего изготовителя. См. Глава 3.9.5.2.9.5 .
2.3 Длина
length Описание. Β элементе < > содержатся сведения ο длине
идентификационной трубки. Если используется, этот элемент должен заполняться β
соответствии σ положениями Глава 3.9.5.2.9.8 .
Примечание
wireLengthType Атрибут предоставляет дополнительные сведения ο длине
для проводов. Он не должен использоваться для описания длины
идентификационных трубок.
length Элемент разметки: < > (O)
2.4 Материал
material Описание. Β элементе < > описываются материалы, из которых
изготовлена идентификационная трубка. Если используется, этот элемент должен
заполняться β соответствии σ положениями Глава 3.9.5.2.9.8 .
material Элемент разметки: < > (O)
Пример разметки:
material Β следующем примере показано использование элемента < > для
идентификационной трубки.
<material>PVC-Nitrile</material>
2.5 Масса
mass Описание. Β элементе < > содержатся сведения ο массе идентификационной
трубки. Если используется, этот элемент должен заполняться β соответствии σ
положениями Глава 3.9.5.2.9.5 .
Пример разметки:
<mass unitOfMeasure="kg">0,0001</mass>
2.6 Ссылка на функциональное описание
Описание. Элемент ссылки на функциональное описание
functionalDescrRef < > содержит ссылки на другие части публикаций об
электрической системе для получения подробных сведений об идентификационной
трубке (κ примеру, описание принципа построения (спецификацию трубки)). Ссылки
должны заполняться β соответствии σ положениями Глава 3.9.5.2.1.2 .
functionalDescrRef Элемент разметки: < > (O)
