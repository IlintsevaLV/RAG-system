2.4.2.1 Объект для замены
replaceObject Описание. Элемент < > представляет один фрагмент модуля
данных, который был изменен σ момента предыдущего издания модуля данных. При
получении нового издания модуля данных этот фрагмент нужно использовать вместо
предыдущего.
Для заданного файла обновления данных можно использовать только объекты,
разрешенные для модуля данных. Например, файл обновления данных, связанный σ
partSpec модулем данных CIR деталей, должен содержать только элементы < >
для замены. (Это правило применяется β модуле BREX по умолчанию).
