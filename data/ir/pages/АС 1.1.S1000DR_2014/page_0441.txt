2.1.1.2 Код модуля данных
dmCode Описание. Элемент < > содержит код модуля данных (DMC) и формирует
часть уникального идентификатора модуля данных. Всем модулям данных
назначается код модуля данных.
Код модуля данных содержит четыре верхних информационных уровня:
идентификация Объекта или тех его компонентов, для которых написан модуль 
данных, с использованием идентификатора модели, отличительного кода
системы, стандартной системы нумерации, кода демонтажа и варианта кода
демонтажа
идентификация типа данных с использованием информационного кода и 
варианта информационного кода
идентификация местоположения, к которому относятся сведения в модуле 
данных, с использованием кода расположения изделия
идентификация типа обучающих материалов в модулях данных обучения См. 
Глава 4.3 .
Для назначения кода модуля данных требуется стратегия кодирования модулей
данных. См. Глава 4.3 .
