2 Применимость
2.1 Понятия применимости
2.1.1 Статическое и фильтрованное представление
2.1.1.1 Фильтрованное представление
С появлением дешевых переносных вычислительных устройств и средств просмотра
стало возможным формировать специализированные представления данных с
фильтрацией по конкретному экземпляру объекта. Возможность создания такого
фильтрованного представления обеспечивается моделью применимости вместе с
определенным набором правил обработки комментариев по применимости.
Например, возьмем для примера набор данных с описанием велосипеда. Модуль
данных S1000DBIKE-AAA-D00-00-00-00AA-258A-A содержит процедурный этап с
комментарием по применимости, в котором указывается, что этот шаг относится к
велосипеду «Модель: Mountain storm, Версия: MK1». В следующем процедурном
этапе есть комментарий по применимости, в котором указывается, что этот шаг
относится к велосипеду «Модель: Brook trekker, Версия: Mk9». Средство просмотра
может использовать комментарии по применимости и известную модель
обслуживаемого велосипеда для фильтрации содержимого модуля данных и
отображения только применимых сведений.
Фильтрацию по применимости также можно использовать для настройки во время
публикации. В этом случае основной модуль данных содержит данные для всех
поставляемых объектов (для всех заказчиков), и во время публикации конкретного
конечного продукта (для конкретного заказчика) производится настройка модуля
данных (фильтрация), из которого берутся только сведения, относящиеся к этому
продукту (заказчику). В примере выше заказчик A перепродает только велосипеды
«Модель: Mountain storm, Версия: Mk1» и ему не нужны данные по велосипедам
«Модель: Brook trekker, Версия: Mk9» в своем руководстве. При публикации все
модули данных адаптируются, и из них удаляются данные по велосипедам «Модель:
Brook trekker, Версия: Mk9». Модель применимости вместе с фильтрацией упрощают
этот процесс. Дополнительные сведения об адаптации модулей данных для
конкретных заказчиков см. в Глава 4.12 .
2.1.1.2 Статическое представление
В странично-ориентированных публикациях или в ситуации, когда средство просмотра
недоступно, необходимо обеспечить поддержку статического представления
применимости и сопутствующих данных. В статическом представлении должны быть
представлены все данные, и организация, занимающаяся техническим
обслуживанием, должна самостоятельно определить, какие данные соответствуют
конкретному экземпляру объекта.
Примечание
Перед публикацией данные должны быть отфильтрованы.
В примере из Разд. 2.1.1.1 потребовалось бы представить оба этапа вместе со
сведениями о применимости для каждого из них. Организация, занимающаяся
техническим обслуживанием, должна самостоятельно решить, какой из двух этапов
относится к ее велосипедам.
2.1.1.3 Издержки функциональности
Модель применимости может поддерживать от очень простых до очень сложных
схем, начиная со странично-ориентированных публикаций и заканчивая
автоматической фильтрацией в средстве просмотра.
