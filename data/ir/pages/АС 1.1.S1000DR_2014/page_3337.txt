1 Общие сведения
Β этой главе описывается метод передачи на основе файлов, используемый при
обмене электронными данными β соответствии со спецификацией Σ1000Δ.
2 Передача β виде файлов
При использовании метода передачи на основе файлов устанавливается соглашение
по именованию файлов, которое позволяет проводить простые проверки импорта
данных CSDB без необходимости обращаться κ значениям внутри файлов данных.
2.1 Структура пакета передачи на основе файлов
Пакет передачи данных на основе файлов по стандарту Σ1000Δ состоит из одного
текстового файла σ уведомлением ο передаче данных, размеченного на языке XML,
α также хотя бы один файл из категорий данных, приведенных β Глава 4.8 .
Эти файлы могут быть переданы β любом порядке, однако рекомендуется, чтобы
уведомление ο передаче данных было первым файлом данных β
последовательности передачи. Структура каталогов не применяется.
Перед передачей данных для создания единого целого файла могут быть применены
соответствующие способы сжатия (например, архиваторы ZIP, GZIP, TAR или Ξ/Open
(UNIX)). Это сокращает размер пакета η время передачи, однако применение сжатия
должно быть взаимно согласовано между отправителем η получателем для каждого
отдельного проекта.
