2.2 Терминология
2.2.1 Профиль приложения
Профиль приложения (AP) является комплектом спецификаций (не считая ISO/IEC
8632), соответствующих определенной среде. Профили используются для
определения подмножеств стандарта ISO/IEC 8632 путем определения элементов,
параметров, вариантов CGM η требований κ реализации, необходимых для
эффективного η однозначного использования стандарта.
2.2.2 Структура приложения
Структура приложения (APS) является последовательностью элементов метафайла,
разграниченных элементами BEGIN APPLICATION STRUCTURE η END APPLICATION
STRUCTURE, содержащих один или несколько необязательных элементов
APPLICATION STRUCTURE ATTRIBUTE η один обязательный элемент BEGIN
APPLICATION STRUCTURE BODY. Структура приложения используется для
группировки элементов CGM для операций выборки, задания гиперссылок η других
операций, зависящих от приложения.
Внутри метафайла структура приложения однозначно задается посредством значения
параметра ID, связанного σ его элементом BEGIN APPLICATION STRUCTURE.
Примечание
Структуры приложения σ разными значениями параметра ID могут иметь любой
уровень вложения.
2.2.3 Элемент СGМ-файла
Элемент СGМ-файла является функциональной единицей, которая может
использоваться для построения изображения или представления сведений.
2.2.4 Генератор CGM
Процесс или оборудование, которое производит CGM-файл, называется генератором
СGМ-файла.
2.2.5 Интерпретатор СGМ-файла
Процесс или оборудование, которое читает CGM-файл η интерпретирует его
содержимое, называется интерпретатором СGМ-файла.
2.2.6 Графические активные участки
Графические активные участки являются графическими объектами, которые участвуют
β создании ссылок.
2.2.7 Графические объекты
Графический объект - это адресуемая логическая единица внутри группы
графических примитивов изображения η/или графических объектов. Такие группы
реализуются по стандарту структуры приложений версии 4 β СGМ-файле η
позволяют связывать σ изображением иерархическую структуру или создавать наборы
графических объектов.
