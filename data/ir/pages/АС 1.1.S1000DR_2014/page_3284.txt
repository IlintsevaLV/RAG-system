2.4.2 Объявление пространства имен
Пространство имен XML объявляется с помощью атрибута, который либо называется
xmlns xmlns , либо содержит : в качестве префикса, за которым следует имя XML,
xmlns задающее рассматриваемое пространство имен. Первая форма атрибута
объявляет, что определенное пространство имен является пространством имен XML
по умолчанию, вторая форма задает префикс пространства имен, используемый для
элементов и атрибутов экземпляра XML.
xmlns Значение атрибута - это название пространства имен в виде ссылки URI.
Пространство имен XML может быть объявлено для любого элемента документа
XML. Пространство имен будет использоваться в области действия данного элемента
(и его атрибутов) и всех его потомков (и их атрибутов), кроме случаев, когда оно
переопределяется или его объявление отменяется. Атрибуты объявления
пространства имен также могут устанавливаться в качестве атрибутов по умолчанию
с фиксированными значениями в схеме XML.
Для переопределения префикса пространства имен следует просто объявить другое
пространство имен XML с тем же префиксом. Для переопределения текущего
пространства имен XML по умолчанию следует объявить используемым по
умолчанию другое пространство имен XML. Префикс пространства имен не может
иметь значение "undeclared". Оно остается в области действия до конца элемента, в
котором оно было объявлено, если только оно не переопределяется. Для отмены
объявления текущего пространства имен XML по умолчанию следует объявить
пространство имен по умолчанию с пустым URI (нулевой длины).
Примечание
Пространство имен XML не применяется к названиям объектов, нотаций и
целевых объектов команд обработки. Соответственно, эти имена не должны
содержать двоеточий.
