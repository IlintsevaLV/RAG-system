2.2 Основной идентификатор
Основной идентификатор является именем элемента или "именем тега".
para Пример: Основным идентификатором элемента < > является "para".
2.3 Атрибут
Атрибут является значением, которое может быть присвоено элементу.
Пример: Значения дня (day), месяца (month) η года (year) являются цифровыми
issueDate issueDate day="30" month="07" атрибутами элемента < >: <
year="2000"/ >.
Атрибуты могут быть либо обязательными (их значение должно быть задано), либо
необязательными. Некоторые атрибуты требуют ввода значения, β то время как для
других атрибутов значения выбираются из имеющегося списка. Определенные
атрибуты имеют значение по умолчанию, которое применяется автоматически, если
значение атрибута не указано.
2.4 Тэг
Начало элемента обозначается открывающим, α конец - закрывающим тегом (кроме
случаев, когда элемент является пустым). Открывающий тег элемента включает из
знак «меньше» [<], затем общий идентификатор, затем, если требуется, набор
атрибутов, завершающийся знаком «больше» [>].
para Пример: Открывающим тегом параграфа является < >.
Закрывающий тег элемента включает знак «меньше» [<], затем знак [/], затем общий
идентификатор, завершающийся знаком «больше» [>].
/para Пример: Закрывающим тегом параграфа является < >.
