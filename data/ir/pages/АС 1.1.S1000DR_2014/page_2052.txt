Код обучения состоит из трех буквенно-цифровых символов.
2 Код обучения
Первым символом кода обучения должна быть либо буква "H", соответствующая типу
повышения производительности труда, либо буква "T" для кодов обучения.
2.1 Повышение производительности труда
Для модулей данных повышения производительности труда последние два символа
определяют конкретный код обучения для сведений о повышении производительности
труда, составляющих содержательную часть модуля данных. См. Глава 8.5.1 .
Пример кода для модуля данных обучения по повышению производительности труда:
S1000DBIKE-A-00-00-00-00A-234A-A-H18A
2.2 Обучающее содержимое
Для модулей данных обучения последние два символа определяют конкретный код
обучения для обучающей информации, составляющей содержательную часть модуля
данных. См. Глава 8.5.2 .
Пример кода для модуля данных обучения:
S1000DBIKE-A-10-10-00-00A-520A-A-T25A
Действительно: Все S1000D-A-04-03-0900-00A-040A-A
