1.1.4 Фильтрация по контексту на основании статических или динамических
сведений о состоянии
Фильтрация данных по контексту означает, что пользователь не выбирает данные
для просмотра, а ему только предоставляется информация, соответствующая
текущей ситуации. Фильтрация обычно привязана к текущей конфигурации или
состоянию Объекта при проведении его технического обслуживания.
Необходимо также проработать случаи, когда фильтрация не связана с
конфигурацией, например:
данные применяются только при нахождении узла на месте эксплуатации, а не в 
зоне для технического обслуживания
данные используются только для определенного диапазона показаний датчика на 
оборудовании
Фильтрация контекста осуществляется путем присоединения условий к фрагментам
данных, описывающих обстоятельства, в которых эти данные применяются.
Например, процедура A может иметь присоединенное условие, согласно которому
она применима, только когда обслуживаемый узел имеет модель "A" с серийным
номером больше 155678. Процедуру A можно увидеть только при данных
обстоятельствах.
Аналогично, процедура В может применяться при питании от аккумулятора, а
процедура C - при питании от вспомогательной силовой установки. В данном случае
процедуры BиC созданы в качестве альтернативы друг другу. Они могут быть
сгруппированы вместе, и при обращении к ним для технического обслуживания,
использоваться будет соответствующая процедура в зависимости от типа
потребляемого питания.
У большинства элементов процессного модуля данных есть присоединенные
элементы "-alt", допускающие подобную группировку элементов данных, которые
применяются для одной и той же цели, но в разных условиях. Элемент "-alt"
является мощным инструментом, позволяющим, например, разработчику создать
процедуру для обработки различных конфигураций Объекта посредством
использования альтернативных шагов, определяемых различиями в конфигурации.
