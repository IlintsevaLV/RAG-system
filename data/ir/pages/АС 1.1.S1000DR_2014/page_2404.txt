2.2.3 Защита планера от коррозии
2.2.3.1 Общие сведения
Защита планера от коррозии является основной темой данных по защите от
коррозии. Каждый основной элемент планера должен быть изучен, содержащиеся
данные должны быть разделены для охвата подверженных коррозии η критических
изделий/участков, методов очистки коррозии, обработки материала, финишной
обработки η герметизации β целях предотвращения коррозии.
Данные по защите от коррозии для систем летательных аппаратов должны быть
предоставлены для каждого из основных элементов планера, представленных ниже:
Система 52 - Двери, люки, створки 
Система 53 - Фюзеляж 
Система 54 - Гондолы/пилоны 
Система 55 - Оперение 
Система 56 - Окна η фонари 
Система 57 - Крылья 
Данные по защите от коррозии для систем наземного η морского базирования
должны предоставляться β зависимости от типа оборудования η содержать
соответствующий номер системы.
2.2.3.2 Описание компонентов (IC 041)
Описательные модули данных должны приводиться для каждого основного элемента
планера (для летательных аппаратов см. Разд. 2.2.3.1). Кроме того, β состав
модулей данных должны входить подверженные коррозии η критические
изделия/участки, α также указываться места, где можно найти конкретные данные по
защите от коррозии.
