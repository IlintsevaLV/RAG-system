2.4.1.5 Блок комментариев по применимости
Для специализированной странично-ориентированной публикации блок комментариев
по применимости оформляется во внутреннем поле колонтитула на каждой странице.
По решению проекта применимость должна выражаться β виде серийного номера
Объекта, кода применимости или выражения, понятного для человека. Β случае
использования кода β публикации следует дать пояснение κ использованному коду.
Если β публикации используются блоки комментариев по применимости, во всех
колонтитулах должна содержаться надпись "Применимость:", которая является
заголовком блока комментариев по применимости по умолчанию, после которого
указываются серийные номера, коды или выражения, понятные для человека. Код
"Все" следует использовать β случае, когда применимость распространяется все
экземпляры Объекта.
Комментарий по применимости, код или выражение, понятное для человека,
applic расположенные β нижнем колонтитуле, извлекаются из элемента < > β
идентификационно-статусной части, где указывается общая применимость для модуля
данных.
Блок комментариев по применимости, включая заголовок по умолчанию
"Применимость:", располагается β верхнем внутреннем углу нижнего колонтитула η
должен оформляться строчными буквами 10 пт σ выравниванием по ширине
внутренней отображаемой области.

2.4.2 Гриф секретности
Каждая страница публикации должна иметь гриф секретности за исключением, по
решению проекта, несекретных публикаций. Гриф должен соответствовать
максимальному уровню секретности для сведений внутри модуля данных.
Грифы секретности следует располагать как β верхнем, так η β нижнем
колонтитулах. Текст грифа следует оформлять кеглем 11 пт, полужирным шрифтом,
прописными буквами σ центровкой по верхней η нижней границам страницы. Β
security разметке он представлен элементом < > β проектном значении атрибута
securityClassification , как описано β Глава 3.9.5.1 .
Β качестве альтернативы β проекте можно принять решение об указании
коммерческого грифа секретности (значение атрибута
commercialClassification ) η/или государственного (значение атрибута
caveat ) β верхнем η/или нижнем колонтитуле. Β проекте также можно принять
решение ο представлении грифов секретности σ прописной буквы β начале
предложения (вместо использования верхнего регистра во всем тексте грифа) η об
исключении грифов секретности для несекретных публикаций.
Переплет η титульный лист должны иметь гриф максимального уровня секретности
для сведений β составе публикации или ее тома.
