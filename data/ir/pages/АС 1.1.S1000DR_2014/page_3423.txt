2.3.4 Обмен сообщениями
Служба поиска может предоставлять дополнительные сведения для запрашивающей
стороны, используя для этого сообщение в ответе. Сообщение содержит текстовую
строку, описывающую сообщение, идентификационный номер и тип сообщения.
Некоторые сообщения должны быть зарезервированы интерфейсом, например, "Not
Found" (Не найдено), "Invalid Query" (Неверный запрос), и т. д.
Номера сообщений должны назначаться согласно следующей схеме нумерации:
‒ 000-299 Зарезервировано для ошибок RDS
‒ 300-599 Зарезервировано для предупреждений RDS
‒ 500-799 Зарезервировано для сведений RDS
‒ 800-999 Зарезервировано для будущего использования
‒ >999 Специальные сообщения реализации RDS
