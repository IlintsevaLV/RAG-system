2.4.3 Разрешение на изменение значения атрибута объекта
Β проекте принимается решение ο допустимости изменений значений, назначенных β
PCT. PCT может назначать только поднабор атрибутов η условий для заданного
объекта, поскольку некоторые значения атрибутов η условий невозможно определить,
пока создается PCT, η/или некоторые атрибуты η условия можно узнать только во
время выполнения (например, скорость ветра, температура). Β проекте необходимо
решить, будут ли во время выполнения получаться только значения для атрибутов η
условий, которые еще не назначены β PCT, или же во время выполнения можно
менять/переписывать назначенные β PCT значения. Изменение назначенных β PCT
значений для данного сеанса программы просмотра может быть необходимым β
проектах, где данные PCT могут неточно отражать конфигурацию объекта на момент
выполнения процедуры.
Примечание
Любое назначение η изменение значений атрибутов во время выполнения имеет
силу только для того сеанса программы просмотра, β котором были внесены
изменения. Изменение источника модуля данных PCT запрещается.
Принятие решения ο правиле выполнения проекта BRDP-Σ1-00548 - Изменение
назначенного значения атрибута объекта.
Решение ο допустимости изменений значений, назначенных β PCT. 
