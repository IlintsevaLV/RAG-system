Примечание
Для одного модуля данных может использоваться только один модуль BREX,
содержащий правила выполнения проекта, применяющиеся конкретно к этому
модулю данных.
В простейшем случае, который также является типовым, для всего проекта будет
использоваться только один модуль данных BREX. Тогда модуль будет кодироваться
на верхнем уровне объекта.
Пример:
Пример кода модуля данных BREX для всего Объекта:
XX - A - 00 - 00 - 00 - 00A - 022A - D (17 символов)
Иногда нужно назначить набор правил выполнения проекта для системы объекта. В
этом случае модуль должен кодироваться с указанием этой конкретной системы.
Пример:
Код модуля данных BREX, относящегося к системе NN Объекта XX (вариант B),
будет выглядеть следующим образом:
XX - B - NN - 00 - 00 - 00A - 022A - D (17 символов)
Когда в проекте требуется более одного модуля данных BREX для одной SNS, для
уникальной идентификации каждого модуля данных BREX должен использоваться код
демонтажа. Первый модуль данных BREX должен иметь код демонтажа 00, а для
последующих модулей данных BREX код демонтажа должен последовательно
увеличиваться.
Пример:
В проекте используется два разных варианта модуля данных BREX. Они оба
применяются на верхнем уровне объекта. Их коды:
XX - A - 00 - 00 - 00 - 00A - 022A - D (17 символов)
XX - A - 00 - 00 - 00 - 01A - 022A - D (17 символов)
