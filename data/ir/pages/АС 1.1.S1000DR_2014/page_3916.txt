913 Общие процедуры ТО
Под кодом 913 приводится процедура общего технического
обслуживания η общепринятые методики технического обслуживания,
которые не указаны β других кодах. Данный код используется для
определения процедуры β тех местах, где приведены только общие
сведения по техническому обслуживанию. Код используется для
определения небольших процедур по
сборке/очистке/проверке/ремонту/разборке, которые слишком
незначительны для создания собственного модуля данных или же
всегда выполняются вместе.
914 Модуль данных контейнера
Под кодом 914 указывается модуль данных контейнера, который
ссылается на различные типы данных или включает их η который не
может обозначаться любым другим специальным информационным
кодом.
915 Вспомогательные комплексы
Под кодом 915 приводится описание вспомогательных комплексов,
необходимых для эксплуатации, технического обслуживания, ремонта
или хранения Объекта.
916 Назначение технического обслуживания
Под кодом 916 приводятся данные по назначению технического
обслуживания для Объекта.
917 Публикация, не соответствующая стандарту Σ1000Δ
Под кодом 917 приводятся публикации, не соответствующие стандарту
Σ1000Δ (например, заимствованные руководства β формате PDF), β
виде стандартного модуля данных, где заимствованные данные
приводятся β виде рисунка.
