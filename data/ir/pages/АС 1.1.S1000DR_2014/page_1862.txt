evaluate Описание. Элемент < > используется для группирования проверок и
содержит логические операции, которые применяются к результатам проверок.
evaluate Элемент < > следует использовать тогда, когда требуется более одного
assert evaluate элемента < >. Элемент < > может содержать другой элемент
evaluate < >, и потому является рекурсивным. Это позволяет создавать очень
сложные комментарии по применимости с помощью несложной структуры, состоящей
только из двух типов элементов.
evaluate Для обработки элемента < > проводится оценка всех дочерних элементов
true false и каждому из них присваивается логическое значение " " или " ". Затем к
результатам применяется логическая операция "и" либо "или", возвращающая общий
true логический результат. Результат " " означает, что соответствующее содержание
false допустимо, а результат " " означает недопустимость такого содержания. Способ
представления допустимости определяется решением на уровне организации или
проекта. В отдельных проектах или организациях может быть принято решение об
удалении недопустимого содержимого, другие могут скрыть его тем или иным
способом.
