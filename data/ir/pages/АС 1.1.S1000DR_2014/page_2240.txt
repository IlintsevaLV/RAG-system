2.4.3.1 Объект для удаления
deleteObject Описание. Элемент < > представляет один фрагмент модуля
данных, который был удален σ момента предыдущего издания модуля данных. При
получении нового издания модуля данных этот фрагмент необходимо удалить. Для
удаленных фрагментов модуля данных β файле обновления данных указывается
только идентификатор объекта для удаления. Это означает, что для файла
deleteObject обновления данных модуля данных CIR деталей элемент < > будет
partIdent partSpec содержать элемент < >, указывающий, что элемент < >,
partIdent содержащий этот < >, необходимо удалить.
Для заданного файла обновления данных можно использовать только объекты,
разрешенные для модуля данных. Например, файл обновления данных, связанный σ
partSpec модулем данных CIR деталей, содержать только элементы < > для
удаления. (Это правило применяется β модуле BREX по умолчанию).
