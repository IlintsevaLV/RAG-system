2.3.13 Стандартные процедуры
Эти модули данных содержат общие сведения, применимые более чем к одной
процедуре, операции или шагу (например, проверка мультиметра для надлежащей
эксплуатации, процедуры заземления Объекта, маркировка пиропатронов).
Каждой процедуре должен быть выделен отдельный модуль данных.
Информационный код должен соответствовать контексту процедуры.
Коды модулей данных должны иметь следующую структуру:
YY-Y-14-32-SS-NNY-YYYY-Z (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-32-SS00-NNYYY-YYYY-Z (37 символов)
2.4 Процедуры загрузки
2.4.1 Общие сведения
Модуль данных общих сведений должен создаваться для каждой единицы штатного
снаряжения, комплекта снаряжения или набора снаряжения (по применимости).
Каждый из этих модулей данных должен содержать перечень (в правильной
последовательности операций) всех модулей данных, которые составляют полную
процедуру загрузки. Заголовки этих модулей данных общих сведений должны
определять применимое снаряжение (например, "Конформный топливный бак для
полетов на дальние расстояния с установленным на нем ИК разведывательным
снаряжением").
Коды модулей данных должны иметь следующую структуру:
YY-Y-14-33-SS-NNY-720Y-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-33-SS00-NNYYY-720Y-A (37 символов)
2.4.1.1 Подготовка снаряжения
Эти модули данных включают процедуры, необходимые для осмотра и подготовки
каждой единицы снаряжения, включая все применимые компоненты. Процедуры
должны быть включены для проверки безопасности каждой единицы снаряжения.
Контекст всех шагов является единичным.
В случае необходимости отдельных модулей данных, их кодирование должно
производиться следующим образом:
YY-Y-14-33-SS-NNYA-720Y-C (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-33-SS00-NNYYY-720Y-C (37 символов)
