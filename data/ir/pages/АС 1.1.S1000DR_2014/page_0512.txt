2.6.1 Разметка только рисунка целиком
2.6.1.1 Добавление
Если добавляется рисунок, добавляется η название рисунка, потому что элемент
title figure < > является обязательным внутри элемента < >. Необходимо
figure присвоить соответствующие значения атрибутам элемента < >.
Пример разметки:
<figure id="fig-0003" changeType="add" changeMark="1"
reasonForUpdateRefIds="rfu-0001">
<title>Title</title>
<graphic infoEntityIdent="ICN-Σ3627-Σ1000Δ0800-001-01"/>
</figure>
2.6.1.2 Изменение
Если изменяется только рисунок, необходимо присвоить соответствующие значения
graphic figure атрибутам элемента < > внутри элемента < >.
Пример разметки:
<figure id="fig-0003">
<title>Title</title>
<graphic infoEntityIdent="ICN-Σ3627-Σ1000Δ0800-002-01"
changeType="modify" changeMark="1"
reasonForUpdateRefIds="rfu-0002"/>
</figure>
2.6.1.3 Удаление
Если удаляется весь рисунок, необходимо присвоить соответствующие значения
figure атрибутам элемента < >.
Пример разметки:
<figure id="fig-0003" changeType="delete" changeMark="1"
reasonForUpdateRefIds="rfu-0003">
<title>Title</title>
<graphic infoEntityIdent="ICN-Σ3627-Σ1000Δ0800-003-01"/>
</figure>
Примечание
Графика все равно переиздается.
2.6.2 Разметка только названия рисунка
Разметка только названия рисунка поддерживает стандартное странично-
ориентированное представление.
2.6.2.1 Добавление
figure Названия рисунков являются обязательными внутри элемента < > η могут
добавляться только вместе σ рисунком. См. Разд. 2.6.1.1.
2.6.2.2 Изменение
Если изменяется название рисунка, необходимо присвоить соответствующие значения
title figure атрибутам элемента < > внутри элемента < >.
