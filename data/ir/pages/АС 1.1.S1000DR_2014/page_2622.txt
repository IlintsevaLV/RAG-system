2.2.6.6 Инструкции по выполнению
Основной раздел "Инструкции по выполнению" содержит пошаговые процедуры (см.
Рис. 1) выполнения задач сервисного бюллетеня. Сложные процедуры можно разбить
на иерархию наборов задач (см. Рис. 1) η процедур.
Набор задач сервисного бюллетеня - это утвержденный набор рабочих инструкций,
подлежащих выполнению до последующей эксплуатации объекта (см. Глава 9.2 ). Κ
типам наборов задач сервисного бюллетеня относятся модификация, осмотр, ремонт,
оценка η административные (список неполный). Внутри набора задач сервисного
бюллетеня можно представить следующие разделы: Общие сведения, распределение
работ, процедура, испытания, завершение работ.
Процедура сервисного бюллетеня является частью набора задач сервисного
бюллетеня. Набор задач сервисного бюллетеня разбивается на процедуры сервисного
бюллетеня, содержащие рабочие инструкции, выполняемые β указанной зоне
персоналом σ заданной квалификацией σ помощью выделенного набора (комплекта)
материалов. Существует несколько типов процедур сервисных бюллетеней, например,
снятие, установка, испытание. Процедуру сервисного бюллетеня можно рассматривать
как основу для создания рабочих карт. Отдельную процедуру сервисного бюллетеня
можно выполнять одновременно σ другими процедурами сервисного бюллетеня.
Инструкции по выполнению (β основном сервисном бюллетене) составляют набор
высокого уровня β иерархии шагов η β основном содержат ссылки на модули
данных. Шаги не должны содержать подробные инструкции η сами процедуры.
Однако, если иллюстраций не требуется, η расходные детали отсутствуют, можно
включить простую процедуру непосредственно β основной сервисный бюллетень, не
используя каких-либо модулей данных технического обслуживания по ссылке.
