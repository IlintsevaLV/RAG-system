Связь между файлом обновления данных и модулем данных CIR состоит в том, что
файл обновления данных может быть связан только с одним модулем данных CIR .
И фрагмент, и модуль данных CIR также должны иметь один тип. Например, один
файл обновления данных "Деталь" напрямую связан с одним и только одним
модулем данных CIR деталей. При соблюдении этого ограничения файл обновления
данных также может использоваться для обновления других сведений в этом модуле
данных CIR. Такие сведения ограничиваются:
