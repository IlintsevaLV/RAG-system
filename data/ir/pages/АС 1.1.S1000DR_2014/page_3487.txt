2.2.2 Вычисление комментариев вычисления
evaluate Элемент < > объединяет несколько проверок и содержит логические
операции, которые применяются к результатам отдельных проверок. Результатом
логической операции является логическое значение "true" или "false".
2.2.2.1 Компоненты комментария вычисления
Комментарии вычисления содержат следующие вычисляемые компоненты,
используемые во время вычисления:
operator атрибут , содержащий операцию, которую необходимо выполнить 
assert содержимое, состоящее из любой комбинации элемента < > и элемента 
evaluate < >, каждый из которых сам по себе дает результирующее логическое
значение "true" или "false"
2.2.2.2 Правила вычисления
operator and 1 Если атрибут принимает значение " ":
Если все дочерние элементы имеют логические значения "true", то 
результатом вычисления будет логическое значение "true".
Если любой из дочерних элементов имеет логическое значение "false", то 
результатом вычисления будет логическое значение "false".
operator or 2 Если атрибут принимает значение " ":
Если любой из дочерних элементов имеет логическое значение "true", то 
результатом вычисления будет логическое значение "true".
Если все дочерние элементы имеют логические значения "false", то 
результатом вычисления будет логическое значение "false".

Созданным комментарием по применимости, предназначенным для человека, можно

applic < > в модулях данных). Программы просмотра во время отображения также

displayText если в элементе < > нет доступных данных.
