3 Глобальные свойства
Глобальные свойства создаются в модулях данных ACT и CCT как элементы
productAttribute cond < > и < >. См. Глава 4.14.1 и Глава 4.14.2 . Ниже
productAttribute cond разбираются атрибуты элементов < > и < >, относящиеся
к работе процессного модуля данных.
3.1 Определение глобальных свойств
Глобальные свойства уникально определяются комбинацией идентификатора атрибута
объекта или идентификатора условия и типа глобального свойства, который
определяет, объявлено ли свойство как атрибут объекта или как условие.
Идентификатор атрибута объекта объявляется в модуле данных ACT в элементе
productAttribute id < > с атрибутом . Идентификатор условия объявляется в
 cond id CCT в элементе < > с атрибутом . Тип глобального свойства определяет,
объявлено ли свойство как атрибут объекта или как условие.
Оба типа глобальных свойств указываются по типу (атрибут объекта или условие) и
id соответствующему атрибуту .
3.2 Типы значений
Глобальные свойства атрибута объекта имеют тип, заданный элементом
productAttribute valueDataType < > с атрибутом .
Глобальные свойства условия имеют тип, заданный по ссылке с помощью элемента
cond condTypeRefId < > с атрибутом .
Основные типы локальных переменных поддерживаются в обоих случаях, за
исключением типа "множество". См. Разд. 2.3.
3.3 Область действия
Для глобальных свойств область действия не предусмотрена. Они считаются
глобальными.
3.4 Диалоги
Для формирования вопросов диалога к пользователю с целью получения значения
глобального свойства атрибута объекта может использоваться дочерний элемент
prompt displayName productAttribute < > или < > элемента < > из модуля
данных ACT . Когда требуется диалоговое меню, для создания пунктов меню со
enumerationLabel значениям глобальных свойств можно использовать атрибут
enumeration productAttribute дочернего элемента < > для элемента < >.
Для формирования вопросов диалога к пользователю с целью получения значения
prompt глобального свойства условия может использоваться дочерний элемент < >
cond элемента < > из модуля данных CCT. Когда требуется диалоговое меню, для
создания пунктов меню со значениям глобальных свойств можно использовать
enumerationLabel enumeration атрибут дочернего элемента < > для
condType элемента < >.
Диалоги, относящиеся к определению глобальных свойств, могут быть описаны в
dialog процессном модуле данных с помощью элемента < >. См. Глава 7.6.1.5 .
