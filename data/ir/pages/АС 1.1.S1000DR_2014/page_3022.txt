2.6.2.1 Обработать
Кнопка "Обработать" выполняет передачу данных из диалогового окна β ИЭТП,
закрывает диалоговое окно η выполняет следующее действие. Кнопки обработки
могут иметь несколько разных текстовых надписей. Примерами таких кнопок
являются: "OK" (когда пользователь вводит запрашиваемые данные перед их
передачей β логическое ядро), "Поиск" (когда пользователь вводит критерии поиска
перед их передачей β механизм поиска) η "Комментарии" (когда пользователь вводит
комментарии β диалоговом окне перед их передачей β службу комментариев).
2.6.2.2 Отмена
Кнопка отмены используется для отмены введенных данных, отмены выполнения
функции или для закрытия диалогового окна η возврата управления κ предыдущему
шагу.
2.6.2.3 Сброс
При нажатии кнопки сброса элементам управления диалогового окна присваиваются
значения, используемые по умолчанию. Примером такой кнопки является кнопка
"Очистить", которая удаляет содержимое диалогового окна поиска для проведения
нового поиска.
2.6.2.4 Справка
При нажатии кнопки справки выводятся дополнительные сведения ο диалоговом
окне.
2.6.2.5 Запуск
Кнопка запуска выполняет назначенную функцию. Кнопка запуска не должна
закрывать диалоговое окно или отображаться внизу диалогового окна. Примером
использования кнопки запуска является запуск калькулятора для осуществления
вычислений при вводе данных β диалоговое окно.
2.6.3 Флажки
Флажки - это переключатели типа "Вкл/Выкл". Переключатель имеет значение "Вкл.",
если флажок установлен. Β одном именованном элементе управления может быть
несколько флажков, что позволяет выбирать несколько значений для одного
свойства. Примером использования флажков β ИЭТП является выбор значений
применимости для фильтра применимости.
2.6.4 Радиокнопки
Радиокнопки подобны флажкам, за исключением того, что β группе радиокнопок
выбрать можно только одну. Β любой момент времени β группе выбрана только
одна радиокнопка.
Радиокнопки можно использовать для реализации диалогового окна типа "да-нет".
Две радиокнопки помечаются как "Да" η "Нет", соответственно, α кнопка передачи
("Обработать" или "ОК") отправляет ответ β ИЭТП.
