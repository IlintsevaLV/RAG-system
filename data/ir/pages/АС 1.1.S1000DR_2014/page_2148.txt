Любой многоуровневый модуль данных BREX должен содержать только ограничения
правил, определенных в модуле данных BREX, на котором он основан. Например,
если в модуле данных BREX организации определенное значение ограничивается
диапазоном от A до M, то в модуле данных BREX проекта, основанном на таком
модуле данных BREX компании, также не должны допускаться значения вне
диапазона A-M. Однако в нем это ограничение может усиливаться (например,
диапазоном A-H).
В проекте или организации необходимо убедиться, что между различными правилами
выполнения проекта внутри иерархической структуры модуля данных BREX нет
конфликтов. Правила в определенном модуле данных BREX должны основываться
на правилах из модуля данных BREX, на который он ссылается (т. е. на правилах
уровня выше). При наличии конфликтов между двумя этими модулями приоритет
имеют правила из модуля данных BREX более высокого уровня. Правила и
процедуры разрешения конфликтов между правилами выполнения проекта см. в
Глава 2.5.1 . Кроме того, в Глава 7.9 приводится руководство по проверке наличия
конфликтов между многоуровневыми правилами BREX.
Следует отметить, что модуль данных BREX в многоуровневой иерархии не
обязательно должен включать повтор правил, приведенных в модуле данных BREX,
на котором он основан. Достаточно указать дополнительные специальные
ограничения, которые применяются на его уровне. Поэтому с целью обеспечить
наличие полного набора правил BREX для конкретного модуля данных необходимо
предоставить всю иерархию модулей данных BREX вплоть до уровня модуля данных
BREX по умолчанию для спецификации S1000D.
Любая многоуровневая иерархия BREX заканчивается модулем данных BREX по
умолчанию для спецификации S1000D. См. Глава 4.10.3 . Эта иерархия отражает
соответствующие уровни в правилах выполнения проекта, где основой для любого
определенного набора правил выполнения проекта (многоуровневого или нет)
является сама спецификация S1000D.
Примечание
Модуль данных BREX для любой конкретной среды обычно не содержит
определений правил, которые применяются к ней, независимо от того, являются
ли они универсальными правилами для среды или применяются конкретно к
модулю данных BREX. Таким образом, процедура проверки модуля данных BREX
может незначительно отличаться от проверки модулей данных в целом, поскольку
его можно проверить в соответствии с содержащимися в нем правилами помимо
правил, содержащихся в модуле данных BREX, на который он ссылается.
