2.5.12 Данные, не соответствующие стандарту S2000M
genericPartDataGroup Описание. Элемент < > используется для хранения
любых данных для конкретных программ.
Текущая структура иллюстрированного каталога сильно зависит от организации
данных S2000M. Для проектов, в которых не используется стандарт S2000M,
некоторые особые данные могут не укладываться в структуру элементов S2000M. В
этом случае данный элемент позволяет определять и хранить любые, отсутствующие
в S2000M элементы, внутри содержимого иллюстрированного каталога деталей.
Тем не менее, группа разработки иллюстрированного каталога деталей сначала
должна проанализировать соответствие между исходными данными и элементами
S2000M, на которые уже ссылаются имеющиеся элементы схемы IPD. Если имеются
совпадения, необходимо использовать существующий элемент S2000M, в противном
случае новые данные помещаются в новый элемент с соответствующим названием.
Примечание
Модули данных иллюстрированного каталога деталей, не соответствующего
стандарту S2000M, должны соответствовать правилам, определенным для
модулей данных структурированных каталогов.
