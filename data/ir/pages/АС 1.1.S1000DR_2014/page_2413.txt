2.4 Модули данных по хранению
Модули данных хранения содержат все данные, необходимые персоналу
технического обслуживания для хранения, осмотра во время хранения и снятия с
хранения отдельных Объектов.
Как правило, достаточно перекрестной ссылки на существующие модули данных.
Информационный набор хранения должен, помимо прочего, охватывать следующие
типы модулей данных:
Общие сведения по хранению Объектов, включающие определения типов 
хранения
Временное хранение 
Длительное хранение 
Консервация 
Удаление консервирующих материалов 
Процедуры по установке изделий в контейнеры 
Процедуры по извлечению изделий из контейнеров 
Процедуры по поддержанию работоспособности изделий во время хранения 
Перемещение изделий, находящихся на хранении 
Подготовка изделий к эксплуатации после хранения 
Приемка изделий, снятых с хранения, перед эксплуатацией 
Данные по продолжительности хранения изделий 

период хранения.
2.4.1 Общие сведения по хранению Объектов
Настоящие модули данных содержат описание назначения сведений по хранению
Объектов, методов использования этих сведений и стандартов проведения
регулярных процедур во время хранения. В качестве источника дальнейших общих
сведений по хранению допускаются перекрестные ссылки на другие материалы.
Сведения по расходным материалам, инструментам и оборудованию должны
содержать перекрестные ссылки на соответствующие (сводные) списки. Должны быть
включены определения типов хранения.
Коды модулей данных должны иметь следующую структуру:
YY-Y-10-30-00-NNA-800Y-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y10-30-0000-NNAAA-800Y-A (37 символов)
