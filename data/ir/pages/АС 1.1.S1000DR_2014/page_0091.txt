Уровень гражданской авиации используется для определения всеобъемлющего
набора правил выполнения проекта, которые будут оставаться неизменными для
всех приложений авиационной промышленности. Проектный уровень используется
для определения специфических для конкретного проекта правил, которые не входят
ни в один набор.
Разбиение на уровни - это только одно измерение "каскадной" структуры правил
выполнения проекта. Альтернативой может служить представление правил
выполнения проекта в виде древовидной структуры. На Рис. 6 представлен пример
такой древовидной структуры правил выполнения проекта. На этом рисунке вдоль
"вертикальной" оси легко читается разбиение на слои, представленное на Рис. 4.
