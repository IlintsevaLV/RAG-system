1 Общие сведения
1.1 Назначение
Β этой главе представляется ряд атрибутов со значениями η интерпретациями,
которые могут быть настроены под конкретный проект или организацию.
Σ1000Δ также предоставляет средства для управляемой адаптации этих атрибутов.
Это допускается для атрибутов, которые не являются критичными для применения
спецификации.
Примечание
Вся адаптация должна проводиться так, чтобы обеспечивать максимальную
совместимость.
2 Настройка атрибутов
Глава 3.9.6 - содержит список соответствующих атрибутов, включая наборы
определенных значений.
2.1 Метод адаптации
Для каждого настраиваемого атрибута стандарт Σ1000Δ предусматривает набор
значений. Для части данных значений β стандарте Σ1000Δ имеется интерпретация
