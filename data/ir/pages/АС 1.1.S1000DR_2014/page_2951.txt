содержать отметок об изменениях.

2.14 Ссылки
Ссылки на модули данных и технические публикации приводятся в алфавитном
порядке, начиная с модулей данных, под заголовком по умолчанию “Ссылки” в
начале модуля данных, а затем и в виде внутренних ссылок в тексте.
2.14.1 Таблица ссылок в модулях данных
Описательные, модули данных технического обслуживания, модули данных поиска и
устранения неисправностей, планирования технического обслуживания и др.
включают стандартную таблицу ссылок, которая непосредственно следует за
перечнями во вступительной части документа: Содержание, перечень таблиц или
перечень рисунков. Над таблицей ссылок указывается заголовок "Ссылки" (Заголовок
с выравниванием по центру №2), для получения в итоге заголовка "Табл. 1" с
названием "Ссылки".
Для всех модулей данных и публикаций, на которые есть ссылка в модуле данных,
в таблице представлены код модуля данных, код модуля публикации или код
публикации, не соответствующей стандарту S1000D, вместе с соответствующим
refs названием, заданным элементом < >. Публикации, не имеющие кода,
приводятся только по своему названию. Это означает, что:
dmRef Ссылка модуля данных берется из элемента < >, который указывает код 
dmCode модуля данных из элемента < >, содержащегося в элементе
dmRefIdent < >.
issueInfo Для проектов, которые включают номер издания (в элементе < >,
dmRefIdent содержащемся в элементе < >) в ссылке модуля данных, номер
издания будет отображаться после кода модуля данных, и ему должно
предшествовать слово “Издание”.
Для проектов, которые включают название модуля данных (в элементе
dmTitle dmRefAddressItems < >, содержащемся в элементе < >) в ссылке
модуля данных, название модуля данных будет отображаться во втором столбце.
