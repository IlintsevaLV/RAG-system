Под кодом 00U приводится набор причин изменений для
информационного массива (публикации или тома публикации).
Дополнительные сведения см. β Глава 3.9.4 .
00V Перечень действующих спецификаций η документации
Под кодом 00V приводится перечень действующих спецификаций η
документации (LOASD). Дополнительные сведения см. β Глава 3.9.4 .
00Ω Таблица перекрестных ссылок по применимости (ACT)
Под кодом 00Ω приводятся объявления атрибутов Объекта, которые
должны использоваться β проекте β выражениях применимости, β
пределах применимости таблицы перекрестных ссылок, совместно со
ссылками на PCT η CCT.
00Ξ Общий информационный репозиторий элементов управления η
индикаторов
Под кодом 00Ξ приводится перечень элементов управления η
индикаторов.
00Y Перечень схем η форм
Под кодом 00Y приводится перечень схем η форм, которые могут
требоваться β разделе служебной информации. Он также может
использоваться для указания самих схем η форм (например,
необходимых β данных для экипажа).
00Z Перечень таблиц
Под кодом 00Z приводится перечень таблиц для технических данных,
которые обычно приводятся β разделе служебной информации.
0Α1 Репозиторий функциональных η/или физических областей
Под кодом 0Α1 приводится функциональная η/или физическая
классификация функциональных η/или физических областей.
0Α2 Репозиторий выражений применимости
Под кодом 0Α2 приводятся выражения применимости, используемые во
всех модулях данных.
0Α3 Каталог таблицы перекрестных ссылок по применимости
Под кодом 0Α3 приводится каталог таблицы перекрестных ссылок по
применимости, который используется β проектах σ участием нескольких
партнеров σ несколькими наборами таблиц ACT/CCT/PCT. Он отражает
связи между разными наборами таблиц ACT/CCT, входящими β проект.
0Β0 Планирование технического обслуживания
Под кодом 0Β0 приводятся сведения, необходимые для определения
задач планового ТО.
0Β1 Временные ограничения
Под кодом 0Β1 приводятся рекомендованные сроки проведения
проверок, технического обслуживания η капитального ремонта Объекта,
его систем, подсистем η сроки службы отдельных деталей.
0Β2 Перечень задач технического обслуживания/проверки систем
Под кодом 0Β2 приводится перечень запланированных задач, которые
должны выполняться для систем η силовой установки Объекта. Для
каждой задачи можно указать ссылку на соответствующую процедуру.
