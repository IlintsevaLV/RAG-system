Описание
1 Общие сведения
Файл обновления данных представляет собой специальный тип объекта CSDB. Этот
файл можно использовать для доставки фрагментов из конкретного модуля данных
общего информационного репозитория (CIR). Это фрагменты, которые были
добавлены, удалены, изменены или восстановлены σ момента прошлого издания
модуля данных CIR. См. Глава 4.13.1 .
Примечание
Применение файла обновления данных ограничивается обновлением модулей
данных CIR, η его можно использовать только β рамках обмена данными.
Он позволяет избежать доставки целого модуля данных. Преимущество
использования файла обновления данных состоит β оптимизации обмена данными за
счет сокращения объема "пакета обмена данными CSDB". См. Глава 4.13 .
