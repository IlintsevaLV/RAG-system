Сократить объем обмениваемых данных 
Упростить обмен данными между компаниями-партнерами, субподрядчиками и 
заказчиками, которым нужно обрабатывать и модифицировать данные
Вместо дублирования свойств какого-либо общего информационного объекта при
каждом использовании в модуле данных модуль данных CIR позволяет собрать такие
свойства в одном месте. Когда такие свойства используются в модулях данных
технического обслуживания, в них можно указывать ссылку на модуль данных CIR.
Устранение дублирования обеспечивает согласованность данных в публикации.
Примечание
Репозиторий CIR обеспечивает согласованность данных благодаря управлению
внутренними хранилищами в производственной среде для многократного
использования данных. Это часто используется для описания инструментов,
расходных материалов и предупреждений и пр.
Сокращение объема обмениваемых данных помогает:
Ускорить загрузку данных через сеть. Данные могут загружаться через сеть 
заказчиками, которые затем будут с ними работать. Также может возникнуть
необходимость загрузить данные, например, в бортовой компьютер летательного
аппарата. Необходимость ускорить загрузку особенно остра в условиях, где
используются другие, менее эффективные технологии.
Сократить время обработки и гарантировать согласованность данных для 
заказчиков, которые хотели бы извлекать и загружать общие данные в базы
данных. Например:
• Реализация модуля данных CIR внешних комментариев по применимости
может значительно сократить объем обмениваемых данных, поскольку
комментарии по применимости сохраняются в модуле данных CIR один раз,
после чего на них ссылаются из всех других модулей данных. Более того,
для проектов, в которых модули данных часто переиздаются только из-за
изменений комментариев по применимости, использование модуля данных
CIR внешних комментариев по применимости позволяет избежать доставки
модулей данных в результате изменения только сведений о применимости.
• Доставка предупреждений с помощью модуля данных CIR предупреждений
позволяет заказчикам, желающим перевести предупреждения на какой-либо
язык, перевести только модуль данных CIR предупреждений вместо перевода
всех вхождений предупреждений в различных модулях данных.
3.2 Публикация
Модули данных CIR можно использовать для публикации структурированных данных
в соответствии с выделенной Схемой общего репозитория. Такая выделенная Схема
позволяет использовать семантические теги для данных, которые можно связывать с
расширенными функциями в ИЭТП.
Например, при использовании модуля данных CIR зоны подробные сведения о зонах
можно публиковать в виде документа в странично-ориентированной публикации.
После этого репозиторий CIR зон можно представить в виде объединенного перечня
данных по зонам для публикации или пакета публикации. В случае публикации
модуля данных CIR в проекте можно представить вводный текст, заполнив элемент
commonInfo < > в модуле данных CIR.
