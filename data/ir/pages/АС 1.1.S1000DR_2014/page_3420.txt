2.2.3 URN для поиска URL или наоборот (N2Λ/Λ2N)
Данная функция находит URL по URN или наоборот. Служба принимает URN или
URL-адрес β качестве параметра запроса η возвращает ХМL-документ, содержащий
характеристику URL-адреса. Если ресурс может быть возвращен β нескольких
форматах, служба предоставляет один, который считается ресурсом по умолчанию,
или ресурс, наиболее подробно определенный посредством дополнительных
параметров. Ошибка 004 "Unknown Resource" (Неизвестный ресурс) показывает, что
URL-адрес не найден.
urn Формат запроса : запрос N2Λ принимает параметр запроса N2R, α
url зарезервированный параметр без значения используется для запуска данной
службы. Служба возвращает URL-адрес или сообщение об ошибке β виде XML-
документа. Данная функция является специальной формой N2C, β которой
url зарезервированный параметр должен распознаваться всеми службами. Если
multiple ресурс существует β нескольких форматах, параметр требует от службы
вернуть несколько блоков описания ресурса, описывающих каждый формат, иначе
возвращаются сведения ο формате по умолчанию. Λ2N принимает URL-адрес β
url качестве зарезервированного параметра η возвращает URN, используя параметр
urn без значения.
Пример возвращения URL-адреса указанного ресурса на английском языке:
http://urn.server.com/urnService?urn=URN:NID:NSS&url&lang=EN

эквивалентность.
