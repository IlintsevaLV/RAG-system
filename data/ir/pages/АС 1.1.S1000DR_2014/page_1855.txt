содержательную часть сведения о применимости, не входящие в применимость,
указанную на уровне модуля данных, запрещено.
2.1.2 Ветви применимости
applic Сведения о применимости содержатся в элементе < >, они имеют
одинаковую структуру, независимо от того, относится ли применимость ко всему
модулю данных или к части содержимого, а также от того, является она внешней
или нет.
applic Элемент < > имеет две логические ветви (три ветви для процессных
модулей данных), которые используются в разных целях:
Комментарий по применимости, предназначенный для человека – состоит из 
displayText элемента < >, содержащего сведения по применимости,
предназначенные для человека. При необходимости эта ветвь применяется
совместно с одной из двух других ветвей.
assert Комментарий по вычисляемой применимости – состоит из элемента < > 
evaluate и элемента < >, содержащих сведения о применимости в
вычисляемом формате, которые можно использовать для динамического
отображения содержимого, снабженного комментариями.
Выражение применимости процессного модуля данных – состоит из элемента 
expression < >, содержащего выражение применимости для логического
механизма в процессном модуле данных. Эта ветвь используется только в
процессных модулях данных.
