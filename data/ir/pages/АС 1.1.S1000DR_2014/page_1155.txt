Описание
1 Общие сведения
Схема описания данных по электрооборудованию используется для настройки и
объявления элементов схемы данных по электрооборудованию. Элементы схемы
данных по электрооборудованию, используемые для описания компонентов,
применяемых в электрооборудовании Объекта, рекомендуется определять в модулях
данных описания данных по электрооборудованию для проекта. Неиспользуемые
элементы схемы данных по электрооборудованию нельзя определять в модулях
данных описания данных по электрооборудованию для проекта.
Можно подготовить более одного модуля данных описания данных по
электрооборудованию. Различные модули данных могут содержать определения
используемых элементов на различных языках. Также возможно формировать
различные модули данных описания данных по электрооборудованию для различных
целей. Это означает, что элементы для персонала по техническому обслуживанию
могут отличаться от элементов, предназначенных для персонала, выполняющего
окончательную сборку. Для обмена данными можно использовать модули данных
описания данных по электрооборудованию, в которых определяется
электрооборудование и элементы, предназначенные для обмена.
Описание данных по электрооборудованию может использоваться в интерактивном
руководстве по электрооборудованию для заголовков, кратких описаний или для
настройки и управления интерактивным руководством в соответствии с конкретными
соглашениями об именовании, определенными в проекте или организации.
Общие элементы и атрибуты должны заполняться в соответствии с положениями
Глава 3.9.5.2.1 . В этой главе приводятся рекомендуемые конкретные ограничения по
электрооборудованию.
