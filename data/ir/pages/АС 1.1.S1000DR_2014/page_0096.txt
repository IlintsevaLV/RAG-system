Описание
1 Общие сведения
Указатель правил выполнения проекта представляет собой перечень всех правил
выполнения проекта, определенных в стандарте S1000D. Указатель правил
выполнения проекта позволяет в организациях и проектах определять правила,
ссылающиеся на уникальный идентификатор для каждого правила выполнения
проекта. Идентификатор для каждого правила выполнения проекта назначается один
раз и навсегда и предлагает организациям и проектам способ управлять правилами
выполнения проекта по мере появления новых изданий S1000D.
Каждое правило выполнения проекта определяется в S1000D следующим образом:
Правило выполнения проекта BRDP-S1-NNNNN – Название правила выполнения
проекта:
Описание правила выполнения проекта. 
где
S1 означает, что правило выполнения проекта было создано в S1000D, а NNNNN –
это уникальный номер, назначаемый в S1000D каждому правилу выполнения проекта
в спецификации. Этот номер не меняется в разных изданиях спецификации.
Каждому новому правилу выполнения проекта назначается новый уникальный номер.
Организации могут создавать собственные правила выполнения проекта и управлять
ими так, чтобы во всех проектах внутри этой организации использовались только
собственные правила выполнения проектов. В S1000D настоятельно рекомендуется
использовать для правил выполнения проекта префикс в виде CAGE-кода
организации. То же относится к правилам выполнения проектов для всех уровней
проектов. В S1000D для этого используется префикс "S1".
Собственные идентификаторы организации для правил выполнения проектов при
использовании CAGE-кода должны иметь следующий формат:
BRDP-XXXXX-NNNNN, где
XXXXX – это CAGE-код организации, а
NNNNN – это уникальный номер, назначаемый организацией каждому правилу
Действительно: Все S1000D-A-02-05-0300-00A-040A-A
