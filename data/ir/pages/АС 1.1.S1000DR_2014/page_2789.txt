2.2.3.5 Обычные процедуры
2.2.3.5.1 Общие сведения
Эти модули данных должны в текстовом виде или в форме контрольной карты
содержать все обычные процедуры, необходимые для выполнения полета.
Подробности и описание работы системы должно приводиться в соответствующих
главах по системам. Должно включаться описание обращения с установленным
оборудованием, если оно не рассмотрено в достаточной для экипажа мере в главах
по системам. Может быть включена проверка и правильная установка органов
управления установленного оборудования, если невыполнение данных операций
создаст угрозу безопасности или повлияет на эффективность полета. Назначение,
работа и последствия применения органов управления должны повторяться здесь,
только если требуется уделить им особое внимание. Использование предупреждений,
предостережений и примечаний должно быть сведено к минимуму, чтобы не снизить
их важность.
Коды модулей данных должны иметь следующую структуру:
YY-Y-15-3Y-YY-NNA-XXXY-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y35-1Y-YY00-NNAAA-XXXY-A (37 символов)
Где "XXX":
121 - Предэксплуатационные процедуры (для экипажа) 
131 - Процедуры эксплуатации в обычных условиях (для экипажа) 
151 - Послеэксплуатационные процедуры (для экипажа) 
Где разбиение информационного кода не требуется, используется информационный
код 131.
Описание информационных кодов контрольных карт для летного экипажа 125, 135 и
155 см. в Разд. 2.2.4.
2.2.3.5.2 Специальные процедуры
Могут быть разработаны процедуры для ЛА, выполняющего полет при специальных
условиях, таких как вылет по тревоге или для заданий, требующих промежуточных
посадок. В данных условиях необходимо выполнять только определенные разделы
процедур предполетной подготовки, опробования двигателя и прочих применимых
процедур для обеспечения безопасной эксплуатации. Посадки для дозаправки,
замены экипажа или пополнения боевых запасов и т. д. определяются как
промежуточные посадки. Можно назначить код для идентификации каждого пункта
обычной процедуры, которая должна выполняться при специальных условиях
эксплуатации (например, соединительные элементы внешнего электроснабжения без
кодировки могут проверяться по усмотрению экипажа кроме тех случаев, когда ЛА
поднимается в воздух по тревоге).
2.2.3.5.3 Процедуры по тревоге
Дополнение процедур по тревоге не должно влиять на обычные процедуры.
Структура обычных процедур должна оставаться неизменной, кроме того, в них
можно приводить ссылки на процедуры по тревоге. Поскольку экипаж в условиях
тревоги использует процедуры по тревоге в качестве основной контрольной карты,
эти процедуры должны включать все шаги процедур, необходимых для эксплуатации
ЛА в соответствии с концепцией тревоги. Процедуры по тревоге должны начинаться
