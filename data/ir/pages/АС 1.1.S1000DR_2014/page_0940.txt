2.2.1 Вариант предмета снабжения
subjectVariantSegment Описание. элемент < > используется (β соответствии σ
требованиями Σ2000Μ) для указания сегмента σ вариантом предмета снабжения
(VAS). Он используется β качестве расширения номера IPPN для хранения сведений,
относящихся κ идентификации предмета снабжения (PN, NSCM η NSN), для которого
подготавливается проект начальной поставки. Β тех случаях, когда проект начальной
поставки содержит несколько вариантов предмета снабжения, данный элемент
повторяется столько раз, сколько имеется вариантов (максимум 8, как указано β
Σ2000Μ).
Если элемент не используется, то соответствующие сведения можно получить из
первого модуля данных проекта начальной поставки, то есть из всех первых CSN. Β
отформатированном номере CSN это цифры σ 10 по 13 для шестизначной
стандартной системы нумерации η σ 13 по 16 для девятизначной. Эти четыре
item цифры представляют номер позиции (определяемый атрибутом ) η вариант
itemVariant номера позиции (определяемый атрибутом ).
