2.5.2 Виды и фильтры
2.5.2.1 Виды
Виды позволяют изменить представление данных, например, данные провода в
порядке номера жгута, вид скрученного многожильного провода, вид экранированных
проводов. Рекомендуется, чтобы все виды были контекстно-зависимыми.
2.5.2.2 Фильтры
Фильтры сокращают объем выводимых данных в зависимости от полей данных,
например, представляя провода только одного жгута, подключенного к
электрооборудованию конкретной зоны. Такая обработка данных будет производиться
до тех пор, пока фильтр не будет изменен.
2.5.3 Контекстно-зависимое представление данных
Контекстно-зависимые выборки из основных электрических данных могут
отображаться для всех формируемых данных и других функций интерактивной
публикации по схеме электрооборудования.
Контекстно-зависимое представление данных в интерактивной публикации по схеме
электрооборудования означает, что пользователю предоставляются дополнительные
сведения в зависимости от элемента проводки, на котором сосредоточено внимание
пользователя.
Например, в созданной сети все провода показаны только с их собственным
обозначением, оборудование - с функциональным элементов (также называется
позиционным обозначением). Если пользователю требуются дополнительные
сведения, например, о конкретном проводе, приложение публикации по схеме
электрооборудования предоставит дополнительные сведения, такие как тип провода,
сортамент, цвет и т. д. для данного конкретного провода. Дополнительные сведения
выводятся, когда пользователь наводит курсор мыши на провод или щелкает кнопкой
мыши на проводе.
В созданных перечнях предпочтительно предоставлять ссылки на модули данных,
содержащие чертежи по установке или прокладке жгутов, электромонтажные схемы
или сведения по подготовке и финишной обработке и т. д., в виде скрытой ссылки
на элемент предварительно определенного перечня. Например, при щелчке
обозначения жгута, к которому принадлежит провод, приложение публикации по
схеме электрооборудования покажет ссылки на чертежи по установке или прокладке
для жгута.
