Эти модули данных содержат все процедуры, необходимые для выполнения проверки

2.2.4.8 Стандартные процедуры
Эти модули данных содержат общие сведения, применимые более чем к одной
процедуре, операции или шагу (например, проверка мультиметра для надлежащей
эксплуатации, процедур заземления Объекта, маркировки пиропатронов).
Каждой процедуре должен быть выделен отдельный модуль данных.
Информационный код должен соответствовать контексту процедуры.
Код модуля данных должен иметь следующую структуру:
YY-Y-14-42-SS-NNA-YYYY-Z (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-42-SS00-NNAAA-YYYY-Z (37 символов)
2.2.5 Процедуры загрузки
2.2.5.1 Общие сведения
Модуль данных общих сведений должен подготавливаться для каждой единицы
назначенного военного снаряжения, комплекта снаряжения или набора снаряжения
(по применимости). Каждый из этих модулей данных должен содержать перечень (в
правильной последовательности операций) всех модулей данных, которые составляют
полную процедуру загрузки. Наименование этих модулей данных общих сведений
должно быть связано с применяемым военным снаряжением (например, "Бомбы,
осколочно-фугасные, калибр 500 фунтов, тип MK82 - Snakeye I").
Код модуля данных должен иметь следующую структуру:
YY-Y-14-43-SS-NNA-720Y-A (17 символов)
до
YYYYYYYYYYYYYY-YYYY-Y14-43-SS00-NNAAA-720Y-A (37 символов)
