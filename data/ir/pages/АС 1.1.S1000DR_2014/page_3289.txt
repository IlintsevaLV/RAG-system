2 Метаданные
2.1 Общие сведения
Σ помощью набора атрибутов или элементов метаданные описывают
дополнительные свойства ресурсов помимо идентификатора. Стандартным примером
метаданных являются записи β библиотечном каталоге σ такими элементами, как
автор, название, дата публикации η τ. δ.
Объединение стандартизованных метаданных σ сетевыми информационными
объектами существенно облегчает нахождение ресурсов, их использование η
управление ими благодаря возможности поиска на основе полей, индексации
нетекстовых объектов η разрешения доступа κ заменителю содержимого, который
отличается от доступа κ содержимому самого ресурса.
Хотя все данные, заданные β рамках Σ1000Δ, являются машиночитаемыми, они не
всегда могут быть понятными для машины, например, вопросы "где находятся
модули данных ο демонтаже шасси, изданные за последний год?", или "есть ли β
сети французский перевод этого модуля данных?".
Эта задача может быть решена использованием точных η строгих определений
метаданных.
2.2 Модель описания ресурсов (RDF)
Модель описания ресурсов (RDF) является платформой описания метаданных,
которая обеспечивает взаимодействие между приложениями, которые обмениваются
понятными для машины данными по глобальной сети. Β RDF делается упор на
средства, позволяющие автоматически обрабатывать интернет-ресурсы, поэтому она
предоставляет основные блоки построения, поддерживающие семантическую паутину.
Β общем, RDF предоставляет основу для общих инструментов разработки, обработки
η поиска понятных для компьютера данных β глобальной сети, таким образом
способствуя превращению всемирной сети β машинно-обрабатываемое хранилище
информации.
