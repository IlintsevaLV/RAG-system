2.5.2.5.2 Фрагменты для замены
replaceObject Один экземпляр элемента < > внутри элемента
replaceObjectGroup < > содержит один экземпляр фрагмента, содержимое
которого должно быть заменено β целевом модуле данных CIR. При наличии
нескольких фрагментов одного типа используется несколько экземпляров элемента
replaceObject < >.
Например:
Предыдущее издание целевого модуля данных:

<partSpec id="part-0009">…</partSpec>

<replaceObject>
<partSpec id="part-0008" changeType="modify">…</partSpec>
</replaceObject>

<partSpec id="part-0008" changeType="modify">…</partSpec>

2.5.2.5.3 Фрагменты для удаления
deleteObject Один экземпляр элемента < > внутри элемента
deleteObjectGroup < > содержит один экземпляр фрагмента, содержимое
которого должно быть удалено из целевого модуля данных CIR. При наличии
нескольких фрагментов одного типа используется несколько экземпляров элемента
deleteObject < >.
Β проекте необходимо решить, какие действия будут выполняться σ удаленными
объектами. См. Глава 3.9.5.2.1.1 .
Примечание
Если решено окончательно удалить удаленные элементы из переизданных
модулей данных, то получатель данных физически удаляет элементы из целевого
модуля данных CIR σ идентификатором, который указан β файле обновления
данных.
