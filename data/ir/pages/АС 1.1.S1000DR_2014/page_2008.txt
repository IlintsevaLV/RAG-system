2.1.5 Оценка производительности труда
Требования и соответствующие критерии инструмента оценки, используемого для
определения успеха воздействия в целевой системе, могут регистрироваться в
модулях данных, которые используют информационную модель плана обучения из
схемы обучения. См. Глава 3.9.5.2.13.1 .
Инструмент оценки производительности труда может использоваться для проведения
промежуточной оценки во время разработки и испытания воздействия, чтобы
определить насколько успешным будет воздействие перед его окончательным
выпуском или применением. Он также может использоваться для проведения
суммарной оценки силы воздействия на работника, должность или работу
организации.
2.2 Обучающие материалы
2.2.1 Изложение для технического обслуживания
Модули данных технического обслуживания составляются в объеме и глубине,
которые отражают требования проекта, уровень квалификации персонала и
проводимой деятельности. Эти модули данных обычно создаются для максимально
однозначного описания производимой процедуры и определения последовательности,
которой необходимо придерживаться.
2.2.2 Изложение для обучения
Обучающие материалы, по своей природе, составляются на основе контекста, в
некоторых случаях они представляются в качестве дополнения к сведениям
технического обслуживания, позволяя проводить дальнейшее разбиение элементов
задачи для успешного обучения. Стиль изложения для обучения отражает
требование к передаче знаний учащимся в отличие от изложения для технического
обслуживания, которое предназначено для инструктирования специалиста по
обслуживанию для проведения процедуры. В других случаях обучающие материалы
используются для формирования исходных знаний об Объекте для облегчения
понимания до проведения действий по обслуживанию.
Требования к структуре учебного воздействия могут регистрироваться в модулях
данных, которые используют информационную модель плана обучения из схемы.
Материалы, которые необходимо предоставить во время учебного воздействия, могут
регистрироваться в информационных моделях обзора, содержимого, сводки и оценки
из схемы обучения. См. Глава 3.9.5.2.13.1 .
