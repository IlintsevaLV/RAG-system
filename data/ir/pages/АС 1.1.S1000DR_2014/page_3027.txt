2.15.2 Печать элементов процессного модуля данных
Печать процессного модуля данных чрезвычайно сложная задача из-за программного
характера данных. Целью является представление "программы" процессного модуля
данных в удобочитаемом виде, при котором специалист по обслуживанию сможет
адекватно интерпретировать предварительные условия, заранее заданные данные,
введенные позже данные, логические конструкции "alt", "if" и "loop" для корректного
следования процессу технического обслуживания.
В этом параграфе определяются требования к печати. Тем не менее, для создания
пригодного печатного вывода необходимо уделить значительное внимание структуре
разрабатываемых данных. При необходимости создания печатной версии руководство
по стилю разработки должно ограничивать использование наиболее сложных
конструкций и комбинаций конструкций. Руководство по стилю разработки для
проекта должно разрабатываться с учетом возможностей конечного пользователя для
того, чтобы создать продукт, пригодный к использованию.
