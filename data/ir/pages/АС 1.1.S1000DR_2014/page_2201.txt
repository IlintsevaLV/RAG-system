Рис. 3 Способы создания ссылок
5.1 Способы создания ссылок
5.1.1 Неявные ссылки
Ссылка разрешается с помощью только значений атрибутов идентификатора
zoneNumber информационного типа. Например, с помощью значения атрибута в
zoneRef partNumberValue элементе < > или с помощью значения атрибута и
manufacturerCode partRef атрибута в элементе < >.
5.1.2 Явные ссылки
dmRef Ссылка разрешается с помощью как элемента < > (который указывает на
соответствующий модуль данных CIR), так и значения атрибута идентификатора
элемента рассматриваемого информационного типа, например с помощью значения
zoneNumber zoneRef атрибута в элементе < >. Вместо использования значения
referredFragment атрибута идентификатора можно использовать атрибут в
dmRef элементе < >.
