 5.2.2 Уровни гарантии разработки функции (FDAL) η элемента (IDAL)
Чтобы показать общие принципы назначения уровней гарантии разработки функции η элемента,
можно выделить два этапа σ двумя различными типами процессов разработки: этап разработки
функции η этап разработки элемента.
Этап разработки функции.
На этом этапе формируются требования κ функциям, которые затем распределяются по
элементам. Процесс разработки требований включает валидацию (гарантию полноты η
корректности) набора требований. Уровень строгости процесса разработки требований κ
функциям задаётся уровнем гарантии разработки функции, который ниже по тексту будет
обозначаться как FDAL. Цели, которые должны быть достигнуты, описаны β этом документе. Β
Приложении Α приводится применимость этих целей для каждого FDAL.
Этап разработки элемента системы.

элемента задается уровнями гарантии аппаратуры η программного обеспечения, которые ниже по

архитектурных свойств, которые могли бы быть использованы для минимизации потенциальных
