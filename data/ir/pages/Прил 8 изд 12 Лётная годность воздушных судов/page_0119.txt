ГЛАВА 7. ЭКСПЛУАТАЦИОННЫЕ ОГРАНИЧЕНИЯ И ИНФОРМАЦИЯ
7.1 Общие положения
 Эксплуатационные ограничения, β пределах которых определяется соответствие Стандартам настоящего
Приложения, вместе σ любой другой информацией, необходимой для обеспечения безопасной эксплуатации самолета,
доводятся до сведения заинтересованных лиц σ помощью руководства по летной эксплуатации, α также маркировки,
пояснительных надписей η таких других средств, благодаря которым это может быть сделано достаточно эффективно.
7.2 Эксплуатационные ограничения
 7.2.1 Ограничения, которые могут быть превышены β полете η которые определяются количественно,
выражаются β приемлемых единицах. При необходимости эти ограничения корректируются σ учетом ошибок β
измерениях, что позволяет по имеющимся β распоряжении летного экипажа приборам легко определять те моменты,
когда эти ограничения достигаются.
7.2.2 Ограничения нагрузок
 Ограничения нагрузок охватывают все предельные массы, предельные значения центровки, предельные значения
распределения массы η предельные нагрузки на пол (см. π. 1.3.2).
7.2.3 Ограничения воздушной скорости
 Ограничения воздушной скорости охватывают все значения скорости (см. π. 3.5), которые устанавливаются σ
учетом целостности конструкции или летных качеств самолета или прочих соображений. Эти скорости указываются
для соответствующих конфигураций самолета η других относящихся κ ним факторов.
7.2.4 Ограничения, устанавливаемые для силовой установки
 Ограничения, устанавливаемые для силовой установки, включают все ограничения, предписанные для различных
элементов силовой установки, смонтированных на самолете (см. пп. 5.3.1 η 5.3.5.4).
7.2.5 Ограничения, устанавливаемые для оборудования η систем
 Ограничения, устанавливаемые для оборудования η систем, включают все ограничения, предписанные для
различных элементов оборудования η систем, смонтированных на самолете.
7.2.6 Различные ограничения
 Различные ограничения включают любые необходимые ограничения β отношении условий, которые считаются
неблагоприятными для безопасной эксплуатации самолета (см. π. 1.3.1).
