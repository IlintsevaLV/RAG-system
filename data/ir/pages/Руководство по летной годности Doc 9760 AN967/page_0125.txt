7.3.2 Основания для разработки программы ТО
7.3.2.1 Как правило, программы ТО эксплуатантов должны быть основаны на рекомендуемых изгото-
вителем указаниях по поддержанию летной годности, таких как (но не ограничиваясь ими) отчет совета
по вопросам ТО (отчет MRB), когда это применимо, η документ держателя сертификата типа по планированию
ТО (MPD) η/или какая-либо соответствующая глава руководства по технической эксплуатации (τ. ε. на рекомен-
дуемой изготовителем программе ТО). Для целей утверждения может потребоваться, чтобы эти указания
по выполнению ТО по своей структуре η форме представления были написаны β формате, приемлемом для ВГА.
7.3.2.2 Для проходящего сертификацию типа нового ВС, когда отсутствует ранее утвержденная программа
ТО, β целях подготовки η представления на утверждение реалистичной программы потребуется всесторонняя
оценка эксплуатантом рекомендаций изготовителя (α когда это применимо, η отчета MRB) совместно σ другой
информацией по летной годности.
