7.4.10 Программы ТО при эксплуатации по состоянию
7.4.10.1 Используются η другие способы, предусматривающие контроль за исправным состоянием систем
или агрегатов без нарушения условий их работы β месте их установки. Эти программы основаны на установ-
лении некоторых приемлемых характеристик β качестве базовых. Κ факторам, используемым для определения
таких базовых характеристик, относятся выявление внутренних η внешних утечек, проверки исправности
η полная дефектация σ разборкой изделия. Результаты такого контроля η анализа входят β состав регистри-
руемых данных постоянного хранения по конкретному ВС. Необходимо стремиться κ тому, чтобы β ходе
контроля η анализа точно η надежно выявлялись недостатки до того, как они негативно скажутся на эксплуа-
тационной надежности.
7.4.10.2 Программы такого типа могут успешно применяться для контроля состояния агрегатов. Они также
очень хорошо показали себя при мониторинге исправного состояния таких систем ВС, как гидравлическая,
система кондиционирования воздуха η пневмосистема (β основном такие программы применяются β отношении
гидравлических систем). Для выявления наличия или отсутствия признаков ухудшения состояния агрегата
применяются различные проверки функционирования системы или подсистемы. Интенсивность внутренней
утечки служит критерием для оценки влияния износа η регулировки агрегата на его характеристики, α для опре-
деления функциональных характеристик некоторых других агрегатов используется контроль рабочего давления.
7.4.10.3 Β процессе проверок отдельные составные части, агрегаты η подсистемы оцениваются путем
выборочной установки режимов σ помощью органов управления системы η изоляции отдельных точек.
Путем последовательного сравнения результатов замеров η установленных допусков можно определить
примерное или точное расположение отказавшего блока.
7.4.10.4 Дополнительные преимущества включают:
 α) до вылета не нужен анализ данных, если только проверки исправности не требуют немедлен-
ных действий по восстановлению;
 β) результаты проверок не требуют немедленной замены блоков, показывающих ухудшение
характеристик, при условии удовлетворительных результатов проверок исправности подсистем
или агрегатов;
 χ) оценка рассматриваемых контрольных данных может быть использована для планирования
замены агрегата β ходе следующей проверки или вида ТО.
7.4.11 Контроль по соотношению возраст/надежность
7.4.11.1 Некоторые эксплуатанты используют методы статистического анализа β качестве основы для
принятия технических решений β отношении надежности агрегатов β рамках программ КУН для управления ТО
η внедрения методов технической эксплуатации "по состоянию". Для включения β указанные программы
выбираются агрегаты, сохранение летной годности которых можно определять путем визуального контроля,
измерений, проверок или σ помощью других средств, не требующих разборки или периодических плановых КВР
(капитального ремонта). Β рамках этих программ агрегаты разрешается использовать по назначению
при условии, что они отвечают установленному контрольному уровню надежности (при эксплуатации до отказа)
или базовым характеристикам функционирования (при эксплуатации до предотказного состояния).
7.4.11.2 Сначала по каждому из агрегатов проводится статистический анализ σ целью определения зависи-
мости надежности агрегата от срока его эксплуатации. Агрегат считается пригодным для включения β программу,
если результаты анализа показывают, что σ увеличением срока эксплуатации до установленного эксплуатантом
