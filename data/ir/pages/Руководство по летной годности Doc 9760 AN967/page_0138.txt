η ранее принятой программой корректирующих действий по результатам предыдущего анализа надежности.
Программой КУН должно быть предусмотрено уведомление ВГА β случае введения β действие увеличенных

сможет увеличить периодичность выполнения КВР η проверок. Важно, чтобы эксплуатант строго соблюдал
условия утвержденной программы КУН.
7.4.13 Изменение периодичности η требований κ ТО
Программа КУН не должна допускать корректировки любых элементов CMR η ALI. Элементы CMR
η ALI являются частью процесса сертификации, η β рамках программы КУН эксплуатанта недопустимо увели-
чение установленных ими сроков. Эксплуатант не должен использовать свою программу КУН β качестве
основания для изменения периодичности работ по программе предупреждения η контроля уровня коррозии.
Однако эксплуатант может пользоваться программой КУН для сбора данных, передаваемых впоследствии β ВГА
для обоснования изменений β периодичности регулярно выполняемых работ. Кроме того, изменение периодич-
ности ТО не должно влиять на выполняемые корректирующие действия. Программа КУН должна включать
процедуры для классификации η назначения методов технической эксплуатации η/или работ по ТО η изменения
