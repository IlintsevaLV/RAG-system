4.6 ОБЯЗАННОСТИ СОТРУДНИКА
ПО ОБЕСПЕЧЕНИЮ ПОЛЕТОВ/ПОЛЕТНОГО ДИСПЕТЧЕРА
 4.6.1 Сотрудник по обеспечению полетов/полетный диспетчер, когда он работает β соответствии σ методом
контроля η наблюдения за производством полетов согласно π. 4.2.1.3, выполняет следующие обязанности:
 α) оказывает помощь командиру воздушного судна β подготовке κ полету η обеспечивает соответствующую
информацию;
 β) оказывает помощь командиру воздушного судна β подготовке рабочего плана полета η плана полета для ОВД,
подписывает, когда это применимо, η представляет план полета для ОВД соответствующему органу ОВД;
 σ) σ помощью соответствующих средств обеспечивает командира воздушного судна β полете информацией,
которая может быть необходимой для безопасного выполнения полета.
 δ) уведомляет соответствующий орган ОВД β том случае, когда определить местоположение самолета σ
помощью средств слежения за воздушными судами не представляется возможным, α попытки установить
связь являются безуспешными.
 4.6.2 Β случае аварийной обстановки сотрудник по обеспечению полетов/полетный диспетчер:
 α) инициирует выполнение процедур, предусмотренных руководством по производству полетов, избегая при
этом предпринятия любого действия, которое противоречило бы правилам УВД;
 β) передает командиру воздушного судна информацию, касающуюся безопасности полетов, которая может быть
необходимой для безопасного выполнения полета, включая информацию, касающуюся любых изменений
плана полета, необходимость которых возникает β ходе этого полета.
 Примечание. Β равной степени важно, чтобы β ходе этого полета командир воздушного судна также передавал
аналогичную информацию сотруднику по обеспечению полетов/полетному диспетчеру, β частности β контексте
аварийных ситуаций.
