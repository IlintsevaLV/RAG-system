Приложение 6. Эксплуатация воздушных судов Часть I
9.4.5 Производство полетов по правилам полетов по приборам (ППП)
или ночью на самолетах, управляемых одним пилотом
 9.4.5.1 Государство эксплуатанта предписывает требования κ опыту, подготовке η длительности перерывов β
работе применительно κ полетам на самолетах σ одним пилотом, выполняемым по ППП или ночью.
 9.4.5.2 Рекомендация. Командир воздушного судна должен:
α) для полетов по ППП или ночью иметь налет не менее 50 ч на самолете данного класса, из которых по
крайней мере 10 ч β качестве командира воздушного судна;
 β) для полетов по ППП иметь налет по ППП не менее 25 ч на самолете данного класса, который может быть
частью налета β 50 ч, указанного β подпункте α);
 σ) для полетов ночью иметь налет ночью не менее 15 ч, который может быть частью налета β 50 ч,
указанного β подпункте α);
 δ) для полетов по ППП иметь предшествующий опыт выполнения полетов по ППП на самолетах, управляемых
одним пилотом, включающий :
 ι) не менее 5 полетов по ППП, включая 3 захода на посадку по приборам β течение предшествующих
90 дней на самолете данного класса β режиме полета σ одним пилотом; или
 ii) проверку при заходе на посадку по приборам по ППП на таком самолете β течение предшествующих
90 дней;
 ε) для полетов ночью выполнить не менее 3 взлетов η посадок ночью на самолете данного класса β режиме
полета σ одним пилотом β течение предшествующих 90 дней;
 φ) успешно завершить программы подготовки, которые включают, β дополнение κ требованиям π. 9.3,
инструктаж пассажиров относительно аварийной эвакуации, использование автопилота η упрощенный
метод пользования полетной документацией.
 9.4.5.3 Командир воздушного судна проходит начальную η повторную летную подготовку η квалификационные
проверки, указанные β пп. 9.3.1 η 9.4.4, β режиме полета σ одним пилотом на самолете определенного типа или класса
β условиях, репрезентативных для конкретного полета.
9.5 СНАРЯЖЕНИЕ ЛЕТНОГО ЭКИПАЖА
 Член летного экипажа, пользующийся правами, предоставленными свидетельством, которое выдано σ условием
ношения соответствующих корректирующих линз, имеет запасной комплект корректирующих линз, который
хранится β легкодоступном месте.
