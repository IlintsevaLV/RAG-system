1. ВВЕДЕНИЕ
 1.1 Нижеследующий материал содержит инструктивные указания β отношении структуры η разработки системы
документации эксплуатанта по безопасности полетов. Следует иметь β виду, что разработка системы документации по
безопасности полетов представляет собой цельный процесс, η изменение каждого документа, входящего β систему,
может затрагивать всю систему. Инструктивные указания по разработке эксплуатационных документов подготовлены
государственными η отраслевыми организациями, η ими могут пользоваться эксплуатанты. Однако эффективное
использование этих инструктивных указаний эксплуатантами может быть затруднено, поскольку они разбросаны по
нескольким публикациям.
 1.2 Кроме того, инструктивные указания по разработке эксплуатационной документации имеют тенденцию
затрагивать только один аспект составления документов, например определение формата η оформление документа.
Инструктивные указания редко охватывают весь процесс разработки эксплуатационной документации. Важный
аспект заключается β том, что эксплуатационные документы должны быть согласованы между собой η должны
соответствовать нормативным положениям, требованиям изготовителей η принципам человеческого фактора.
Необходимо также обеспечить согласованность всех разделов η последовательный характер их применения. Таким
образом, делается акцент на комплексный подход, основанный на рассмотрении эксплуатационной документации как
цельной системы.
 1.3 Изложенные β настоящем дополнении инструктивные указания касаются основных аспектов процесса
разработки системы документации эксплуатанта по безопасности полетов σ соблюдением положений π. 3.5 главы 3.
Эти инструктивные указания основаны не только на теоретических исследованиях, но также на существующей

 2.1 Система документации по безопасности полетов должна быть построена согласно критериям, которые
