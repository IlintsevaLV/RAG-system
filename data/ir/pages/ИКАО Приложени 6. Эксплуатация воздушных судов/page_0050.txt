Приложение 6. Эксплуатация воздушных судов Часть I
Программа технического обслуживания. Документ, содержащий описание конкретных плановых работ по
техническому обслуживанию η периодичность их выполнения, α также связанных σ ними процедур, например
программы надежности, необходимых для обеспечения безопасной эксплуатации тех воздушных судов, которых
он касается.
Производство полетов σ увеличенным временем ухода на запасной аэродром (EDTO) . Любые полеты самолета σ
двумя или более газотурбинными двигателями, когда время полета до запасного аэродрома на маршруте
превышает пороговое время, установленное государством эксплуатанта.
Психоактивные вещества. Алкоголь, опиоиды, каннабиноиды, седативные средства η гипнотические препараты,
кокаин, другие психостимуляторы, галлюциногены η летучие растворители; табак η кофеин исключены.
Рабочий план полета. План, составленный эксплуатантом для безопасного выполнения полета σ учетом летно-
технических характеристик самолета, эксплуатационных ограничений η ожидаемых условий на заданном
маршруте η на соответствующих аэродромах.
Располагаемая дистанция прерванного взлета (РДПВ). Располагаемая длина ВПП при взлете плюс длина концевой
полосы торможения, если она предусмотрена.
Располагаемая посадочная дистанция (РПД). Длина ВПП, которая объявлена располагаемой η пригодной для
пробега самолета после посадки.
Ремонт. Восстановление летной годности авиационного изделия после его повреждения или износа для обеспечения
дальнейшего соответствия воздушного судна требованиям κ конструированию, предусмотренным
соответствующими нормами летной годности, которые использовались для выдачи сертификата типа
соответствующему типу воздушного судна.
Рубеж ухода . Самая последняя географическая точка, от которой воздушное судно может продолжать полет по
маршруту до аэродрома назначения, α также до имеющегося для данного рейса запасного аэродрома на маршруте.
Руководство полетами. Осуществление полномочий β отношении начала, продолжения или окончания полета, α
также изменения маршрута β интересах безопасности воздушного судна, регулярности η эффективности полета.
Руководство по производству полетов. Руководство, содержащее правила, инструкции η рекомендации для
использования эксплуатационным персоналом при выполнении своих обязанностей.
Руководство по процедурам организации по техническому обслуживанию. Документ, одобренный руководителем
организации по техническому обслуживанию η содержащий подробную информацию ο структуре организации по
техническому обслуживанию η обязанностях ее руководства, сфере выполняемых работ, производственной базе,
процедурах технического обслуживания η системах обеспечения качества или инспекционных проверок.
Руководство по летной эксплуатации (воздушного судна). Руководство, приемлемое для государства эксплуатанта
η включающее порядок действий β обычной, особой η аварийной ситуациях, контрольные карты, ограничения,
информацию ο летно-технических характеристиках η сведения ο системах воздушного судна, α также другие
материалы, связанные σ эксплуатацией воздушного судна.
 Примечание. Руководство по летной эксплуатации воздушного судна является частью руководства по
производству полетов.
Руководство эксплуатанта по регулированию технического обслуживания. Документ, содержащий описание
процедур эксплуатанта, которые обеспечивают возможность управления своевременным η удовлетворительным
выполнением всех плановых η неплановых работ по техническому обслуживанию воздушных судов данного
эксплуатанта.
