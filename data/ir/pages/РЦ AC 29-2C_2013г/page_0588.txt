РАЗДЕЛ Ε – СИЛОВАЯ УСТАНОВКА
МАСЛЯНАЯ СИСТЕМА.
AC 29.1011. § 29.1011 МАСЛЯНАЯ СИСТЕМА – ОБЩИЕ ПОЛОЖЕНИЯ.
α. Пояснение.
(1) Масляная система, предусмотренная для каждого установленного
двигателя, должна обеспечивать все необходимые двигателю виды смазки η поставлять
масло при температуре β пределах рабочего диапазона, установленного для данного
двигателя при его сертификации.
(2) Располагаемый запас масла каждой масляной системы должен быть
достаточным для обеспечения двигателя маслом при максимальном его потреблении β
критических условиях эксплуатации. Должны удовлетворяться все требования по
циркуляции η ограничению рабочей температуры масла.
β. Процедуры.
(1) Существуют три основных принципа подачи η охлаждения масла для
двигателя. Есть автономные системы (вся система, сертифицированная σ двигателем),
системы, имеющие β своем составе компоненты двигателя η планера, η системы,
которые полностью обеспечиваются компонентами планера. Любой из этих трех
принципов может быть использован для удовлетворения требования независимости
масляной системы для каждого двигателя.
(2) Емкость масляного бака β первую очередь определяется расходом масла
β двигателе. Другие факторы, которые должны учитываться при выборе параметров
системы подачи масла, являются ресурс винтокрылого аппарата β критических условиях
эксплуатации η количество масла, циркулирующего β системе для поддержания
необходимого охлаждения. Адекватность системы подачи масла β двигатель может быть
показана σ помощью расчетов, β сочетании σ данными ο расходе масла двигателем η
данными системы охлаждения. Для поршневых двигателей может использоваться
соотношение одного галлона (3,79 λ) масла на каждые 40 галлонов (151,45 λ) топлива;
однако, может быть η соотношение масла κ топливу меньше, чем 1:40 при правильном
обосновании данных расхода масла β двигателе.
(3) Требования κ охлаждению масла двигателя определяются β §§ 29.1041 –
29.1049. Конструкция масляной системы охлаждения двигателя будет зависеть от
условий жаркого дня, теплопередачи двигателя η других эксплуатационных данных
масляной системы, предоставленных производителем двигателя. Определение размеров
масляного радиатора будет зависеть от данных двигателя η от того, будет ли радиатор
также использоваться для основного охлаждения трансмиссионного масла. Размер
масляного радиатора должен быть как можно меньше из-за его влияния на конструкцию
винтокрылого аппарата, но во всех случаях должно быть продемонстрировано
адекватное охлаждение во всем диапазоне режимов эксплуатации винтокрылого
аппарата.
