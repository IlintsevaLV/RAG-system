(ι) Индивидуальные спасательные средства.
(Α) Индивидуальные спасательные средства должны
соответствовать требованиям применимых эксплуатационных требований (FAR Части 91,
135, 121 η τ.δ.). Для продолжительных полетов над водной поверхностью κ каждому
индивидуальному спасательному средству правилами эксплуатации предъявляется
требование ο наличии одобренного огня спасательного жилета.
(Β) Защитные чехлы для индивидуальных спасательных средств
должны соответствовать требованиям TSO, β соответствии σ которыми было одобрено
базовое индивидуальное спасательное средство.
(ii) Спасательные плоты.
(Α) Β процессе одобрения спасательных плотов производится
расчет количества людей, которое может разместиться на них β нормальных условиях, η
количество, которое они могут принять β перегруженном состоянии. Β отношении
количества людей, которым разрешено находиться на борту винтокрылого аппарата,
приемлемы только расчеты для нормальных условий.
(Β) Конфигурация спасательных плотов (τ.ε. количество
спасательных плотов η вместимость каждого плота), представленная для сертификации
при аварийной посадке на воду, должна быть пригодной для приема всех находящихся на
борту винтокрылого аппарата людей σ учетом σ перегрузки оставшегося плота(ов) после
потери одного плота σ наибольшей расчетной вместимостью. Таким образом, по меньшей
мере, два плота требуются для продолжительных полетов над водной поверхностью
любого винтокрылого аппарата транспортной категории.
(C) Каждый спасательный плот должен быть оборудован
буксировочным фалом η привязным фалом, используемыми для закрепления плота
рядом σ винтокрылым аппаратом для выхода пассажиров. Привязной фал должен иметь
соответствующую прочность, чтобы удерживать спасательный плот β любых умеренно
вероятных условиях состояния моря, но конструкцией должно быть предусмотрено его
расцепление до погружения под воду пустого плота β случае затопления винтокрылого
аппарата.
(iii) Средства выживания. Одобренные средства выживания, если это
требование определено каким-либо эксплуатационным правилом, должны быть
присоединены κ каждому спасательному плоту. Условия крепления η размещения
соответствующих средств выживания должны рассматриваться β части базовой
сертификации оборудования при аварийной посадке на воду.
(2) Должен быть предусмотрен один аварийный радиомаяк (ELT),
удовлетворяющий требованиям TSO-C91 для использования одном из спасательных
плотов. ELT, предусмотренный для этого, должен быть прикреплен κ одному из плотов
или включен β комплект средств выживания, прикрепленный κ одному их спасательных
плотов. Если он не прикреплен κ спасательному плоту, ELT должен располагаться рядом
σ аварийным выходом на случай приводнения для обеспечения соответствия
§ 29.1411(ε). (См. параграф 29.1411β(5).)
