12. СИМВОЛЫ. Символы, используемые β ICA, должны быть перечислены вместе σ
объяснениями во Введении κ ICA.
13. МЕРЫ ПРЕДОСТОРОЖНОСТИ. Мера предосторожности означает меру, принятую
заранее, чтобы предотвратить урон.
α. Все необходимые меры предосторожности должны быть
включены β ICA. См. Приложение Α, Α29.3 (β)(3).
β. Следующие примеры мер предосторожности различаются β
зависимости от серьезности опасности или состояния:
(1) ПРЕДУПРЕЖДЕНИЕ: Означает процедуры технического
обслуживания, действия, состояния η τ.δ., приводящие κ травмам или гибели людей.
(2) ВНИМАНИЕ: Означает процедуры технического обслуживания,
действия, состояния η τ.δ., приводящие κ повреждению или разрушению оборудования.
(3) ПРИМЕЧАНИЕ: Означает процедуры технического
обслуживания, действия, состояния η τ.δ., или формулировки, которые должны быть
выделены.
14. ЕДИНИЦЫ ИЗМЕРЕНИЯ
α. ICA обычно содержат единицы изменения. Это могут быть показания
прибора, температура, давление, допуски, ограничения или значения крутящего
момента.
β. Рекомендуется, чтобы ICA содержали значения как β стандартной
системе единиц измерения США, так η β метрической системе для каждой величины
измерения, допуска или крутящего момента. Приложение таблицы пересчетов не
приемлемо.
15. ICA ДЛЯ КАЖДОГО ДВИГАТЕЛЯ
α. ICA должны включать ICA для каждого двигателя. См. Приложение
Α, Α29.1 (β).
β. ICA для двигателей, имеющих сертификат типа, одобряются
FАА/авиационными властями, ответственными за двигатели, η должны быть
включены β качестве справочного материала β ICA заявителя.
χ. ICA для двигателей без сертификата типа готовятся заявителем η
предлагаются соответствующим FАА/авиационным властям для проверки η оценки.
16. ICA ДЛЯ КАЖДОГО ВИНТА
α. ICA должны включать ICA для каждого винта. См. Приложение Α,
Α29.1 (β).
β. ICA для винтов обычно включаются β ICA винтокрылого аппарата.
17. ICA ДЛЯ КАЖДОГО ТРЕБУЕМОГО УСТРОЙСТВА
α. ICA должны включать ICA для каждого устройства по требованию
FAR/JAR. См. Приложение Α, Α29.1 (β).
