§ 29.1587. Скорость, обеспечивающая минимальную скорость снижения, эффективна при
отказе двигателя на больших высотах, когда пилоту требуется выполнять ограниченные
по времени действия, например, перезапуск двигателя, надувание пневматических
понтонов, радиосвязь η др. Скорость для оптимального угла планирования несколько
выше η наиболее эффективна, когда необходимо достигнуть отдаленного места
приземления. Эта скорость, при соответствующих оборотах несущего винта, позволяет
пролететь максимальное расстояние σ определенной высоты при нулевой ветровой
обстановке.
(3) Третья скорость, рекомендуемая скорость авторотации, может быть
использована β дополнение κ скорости, соответствующей минимальной скорости
снижения η скорости для максимального угла планирования. Как правило, для
рекомендуемой скорости авторотации выбирается оптимальное значение для
обеспечения эффективного выравнивания, но она β то же время должна быть достаточно
мала, чтобы обеспечить контролируемую, относительно медленную посадку.
Рекомендуемая скорость авторотации, как правило, лежит β пределах, соответствующих
минимальной скорости снижения η скорости для максимального угла планирования.
Значение рекомендуемой скорости авторотации должно быть представлено β
руководстве по летной эксплуатации винтокрылых аппаратов. Связь между минимальной
скоростью снижения, скоростью для наилучшего угла планирования η рекомендуемой
скоростью авторотации представлена на рисунке AC 29.71-1.
(4) Переднее положение центра тяжести, как правило, является критическим,
тем не менее, влияние положения центра тяжести должно быть выборочно проверено,
для того чтобы подтвердить это утверждение для данной конструкции.
β. Процедуры.
(1) Испытания проводятся при скоростях, которые ограничивают
предполагаемые скорости до минимальной скорости снижения η оптимального угла
планирования. На графике потребной мощности скорость для минимальной потребной
мощности приблизительно соответствует минимальной скорости снижения. Скорость для
максимальной дальности планирования может быть оценена σ помощью касательной
линии, проведенной из начала координат до кривой потребной мощности.
(2) Испытания для определения характеристик авторотации могут быть
проведены одновременно σ испытаниями для определения характеристик набора
высоты. Требуемые данные похожи для обоих испытаний η иногда более эффективным η
подходящим будет провести чередующиеся наборы высоты η снижения β требуемом
диапазоне высот. Снижения следует выполнять при эквивалентно-обратных курсах, α
результаты усреднять так же, как η при испытаниях на определение характеристик
набора высоты.
(3) Снижение оборотов винта по сравнению σ режимом нормальной
мощности двигателя может повысить характеристики авторотации. Если заявитель хочет
улучшить характеристик авторотации при оборотах значительно более низких, чем β
регулируемом диапазоне или диапазоне σ работающими двигателями, то следует
рассмотреть целесообразность снижения η контроля оборотов на более низких
значениях, α затем увеличения при посадке. При более низких весах η на высотах σ
меньшей плотностью, полностью опущенное положение ручки «шаг-газ» может
автоматически привести κ меньшим оборотам η это, конечно же, приемлемо при условии,
что не превышаются ограничения оборотов σ неработающей силовой установкой.
(4) Следует убедиться β том, что κ приводу винта не подводится мощность от
двигателя, так как даже очень небольшая мощность может значительно повлиять на
характеристики снижения.
