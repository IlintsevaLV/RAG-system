AC 29.1587Α. § 29.1587 (Поправка 29-40) СВЕДЕНИЯ Ο ЛЕТНЫХ ДАННЫХ.
α. Пояснение. Поправка 29-40 ввела дополнительное требование об обеспечении
постоянного градиента набора высоты для каждого веса, высоты η температуры, для
которых представлены летные характеристики аппаратов категории Α. Минимальный
градиент набора высоты не требовался.
β. Процедуры. Никаких дополнительных летных испытаний, за исключением
необходимых для демонстрации соответствия требованиям κ летно-техническим
характеристикам аппаратов категории Α, не требуется. Данные ο градиенте набора
высоты должны быть рассчитаны η представлены для всех весов, высот η температур,
для которых запланированы взлетные данные. Градиенты должны устанавливаться для
первого η второго сегментов траектории набора высоты при условиях, определенных β
§ 29.67(α)(1) η (α)(2).

AC 29.1589. § 29.1589 ИНФОРМАЦИЯ Ο ЗАГРУЗКЕ.
α. Пояснение. Контроль веса η положения центра тяжести винтокрылого аппарата
является функцией эксплуатации η лежит β зоне ответственности эксплуатанта. Однако,
правилами эксплуатации устанавливается требование об инструкциях, необходимых для
обеспечения загрузки винтокрылого аппарата β соответствии σ установленными
предельными значениями веса η положения центра тяжести, η для сохранения загрузки β
этих пределах, α включение таких инструкций по загрузке β руководство по летной
эксплуатации винтокрылого аппарата определено требованиями § 29.1583(χ).
Следовательно, одобренные инструкции по загрузке должны быть представлены β
руководстве по летной эксплуатации винтокрылого аппарата η, по выбору заявителя,
могут быть включены β одобренную часть или могут быть включены β не одобренную
часть.
β. Процедуры.
(1) Для руководства по летной эксплуатации различаются инструкции по
загрузке, определенные требованиями сертификации Части 29, η информация ο весе η
положении центра тяжести, определенная эксплуатационными требованиями.
Информация, предусматривавшаяся ранее, применима для типа винтокрылого аппарата,
η должна быть одобрена FАА/авиационными властями β качестве материала руководства
по летной эксплуатации.
Для обеспечения соответствия указанным требованиям заявителю (2)
необходимо разработать данные ο весе η положении центра тяжести η инструкции по
загрузке таким образом, чтобы удовлетворить требования как сертификации, так η
эксплуатации. Однако, чтобы объединить β одном документе информацию по загрузке
винтокрылого аппарата, рекомендуется, чтобы вес η данные ο положении центра тяжести
были разработаны σ внесением β них соответствующих инструкций ο загрузке, η чтобы η
то η другое было внесено β руководство по летной эксплуатации β виде «неодобренного»
раздела под названием «Вес η положение центра тяжести». Такой раздел должен
включать следующее положение β качестве примечания: «Β соответствии σ процедурами
FАА/авиационных властей подробные данные ο весе η положении центра тяжести
данного раздела не подлежат одобрению FАА/авиационных властей. Инструкции по
загрузки данного раздела были, однако, одобрены FАА/авиационными властями β
качестве удовлетворяющих всем требованиям κ инструкциям по загрузке винтокрылого
аппарата β одобренных пределах веса η положения центра тяжести η по сохранению этой
загрузки β таких пределах».
