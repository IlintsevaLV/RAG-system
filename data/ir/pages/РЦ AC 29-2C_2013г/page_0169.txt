β. Процедуры.
(1) При испытаниях ЛА характеристики резонанса должны быть проверены во
время взлета η посадки при нулевой скорости η во время посадочного пробега, используя
различные режимы мощности двигателя. На всех режимах, любые колебания, которые
могут появиться, должны быть погашены. Кроме того, неустойчивость не должна
возникать при таких рабочих состояниях, как изменение оборотов винта от минимальных
до максимальных η мощности от малого газа до максимальной. Для винтокрылого
аппарата σ шасси, неровность рулежной дорожки β сочетании σ некоторыми скоростями
руления может возбудить земной резонанс. Эти условия должны быть оценены при
рулении по типичным поверхностям. Данная оценка может быть проведена β сочетании σ
испытаниями § 29.235.
(2) Для задания угла общего шага при касании при всех скоростях винта
выполняются медленные вертикальные посадки для каждой конфигурации. Для
аппаратов, оборудованных системами улучшения устойчивости (СУУ), должны быть
проведены все исследования земного резонанса σ включенной η выключенной СУУ. Они
включают взлеты σ зависанием η пробегом η посадки σ пробегом, рулежные испытания η
особые испытания земного резонанса, отмеченные β данном документе. Следует
предусмотреть проведение испытаний при различных конфигурациях СУУ, таких как
включенный канал крена, выключенный канал тангажа, если такие конфигурации
возможны η разрешены.
(3) Для каждой испытываемой конфигурации винтокрылого аппарата, он
вначале должен располагаться на земле σ нулевым углом тангажа η винтом,
стабилизированным при минимальной приемлемой скорости вращения, или, по выбору,
при скорости, которая, согласно расчетам, имеет значительный запас от указанных
резонансных условий. Подайте сигналы на органы системы управления, чтобы возмутить
систему для оценки последующего затухания.
(4) Для каждого приращения скорости вращения винта η для каждой скорости
винта, соответствующей установке общего шага, должны быть исследованы влияния
входных сигналов на органы управления циклическим η общим шагом перед переходом κ
следующей скорости винта. Эти входные сигналы должны перекрывать соответствующий
диапазон η сочетания амплитуды η частоты.
(5) Входные сигналы на орган управления циклическим шагом подаются либо
σ помощью ручки управления, либо через устройство, генерирующее сигнал для органа
управления циклическим шагом. Для каждой частоты входного сигнала амплитуда

подаваться β течение времени, достаточного для выполнения пяти полных оборотов
против часовой стрелки ручки управления циклическим шагом (вокруг нейтрали) при
заданной частоте.
(6) При каждой амплитуде входного сигнала управления циклическим шагом
частота возбуждения должна постепенно увеличиваться до величины, превышающей
