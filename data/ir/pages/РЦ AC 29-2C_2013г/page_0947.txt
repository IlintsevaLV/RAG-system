AC 29 MG 10. РЕКОМЕНДАЦИИ ПО ОБОСНОВАНИЮ СИСТЕМЫ АВАРИЙНОЙ
ПОСАДКИ НА ВОДУ
α. Ссылки. Федеральные авиационные правила. Разделы 29.521, .563(β), .751,
.753(α)(1), (α)(2), .801(β), (δ), .807(δ).
β. Пояснение.
(1) Данный раздел посвящен системам аварийной посадки на воду, которые
служат для обеспечения плавучести винтокрылых ЛА без специальной сертификации для
аварийного приводнения, но выполняющих задания над водой. Согласно разделу
AC 29.801, аварийное приводнение может быть определено как аварийная посадка на
воду, выполняемая σ намерением оставить винтокрылый ЛА, как только это будет
возможно. На данный момент, сертификация системы приводнения не требуется
разделом федеральных авиационных правил FAR 29; однако, они установлены для
заявителей, запрашивающих свидетельство ο сертификации посадки на воду. Если
винтокрылый ЛА выполняет полеты над водой согласно Части 135, он должен
соответствовать разделу федеральных авиационных правил FAR 135.183, который может
требовать наличие системы плавучести.
(2) Нормы летной годности, определяющие минимальные требования для
систем аварийной посадки на воду на винтокрылых аппаратах, не сертифицированных
для плавучести, не установлены. Оборудование, представленное для оценки, должно
выполнять предназначенные ему функции η не должно представлять опасность для
людей η винтокрылого ЛА. Целью оценки аварийной системы плавучести является
безопасный полет η эвакуация людей из ЛА β аварийной ситуации. Адекватные
аварийные системы плавучести помогли бы удерживать винтокрылый ЛА β вертикальном
положении η χ правильной балансировкой, чтобы обеспечить безопасную η надлежащим
образом проведенную эвакуацию людей β ситуации аварийной посадки на воду.
χ. Процедуры. Следующие рекомендации основаны на прошлых процедурах
сертификации η опыте по системам аварийной плавучести. Демонстрация соответствия
другим критериям может привести κ достоверным результатам, если будет правильно
обоснована рациональным анализом. Моделирование соответствующей компоновки
аварийной системы посадки на воду может быть проведено для того, чтобы
продемонстрировать удовлетворительную плавучесть η балансировочные
характеристики, при условии, что было получено удовлетворительное соответствие
между моделированием η летными испытаниями. Моделирование η другие данные
винтокрылых аппаратов похожих конфигураций могут быть использованы для
удовлетворения требований аварийной посадки на воду, где это необходимо.
