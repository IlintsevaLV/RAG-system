(1) Ёмкость аккумуляторной батареи должна быть
достаточной для подачи необходимого тока при уровне напряжения, который обеспечит
надлежащую работу оборудования/выполнение функций, зависящих от мощности
батареи. Необходимо показать, что эта емкость является достаточной, при надлежащих
уровнях напряжения, для всех режимов эксплуатации η условий окружающей среды.
Вертолеты, сертифицированные для полетов по ППП, требуют достаточной мощности
аккумуляторных батарей для приведения β действие минимального набора необходимого
оборудования на период времени, достаточный для того, чтобы найти подходящее место
для посадки η выполнить безопасную посадку. Минимальное время для ППП составляет
30 минут. Кроме того, вертолеты могут использовать электроэнергию для запуска,
батарея должна иметь достаточную ёмкость, чтобы обеспечивать надлежащий запуск
двигателя на земле, α также иметь возможность подавать питание для запуска β полете β
случае необходимости. Потребная мощность для запуска β полете может учитывать
необходимость высокого уровня безопасности β зависимости от системы распределения
энергии η количества двигателей вертолета.

фактором, определяющим количество элементов, которое должна содержать батарея.
Если батарея надлежащим образом не заряжена, то мощность может не обеспечиваться,
когда β этом возникнет необходимость, β соответствии σ требованиями κ аварийным
источникам питания. Никель-кадмиевые батареи σ двадцатью элементами
использовались β течение нескольких лет для предотвращения ухода параметров при

приемлемым источником для штатной зарядки 20-элементной никель-кадмиевой батареи.
