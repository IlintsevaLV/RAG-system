(ii) Методы проверки. Конструктор должен стремиться κ тому, чтобы
обеспечить адекватную возможность для осмотра всех частей конструкции на предмет
оценки отказобезопасного роста повреждений. Рекомендуются следующие способы
проверки конструкций σ безопасным ростом трещин:
(Α) Плановые проверки. Для обеспечения программ плановой
проверки следует, по возможности, избегать «слепых зон», недоступных для визуального
осмотра.
(Β) Специальные проверки. Эти проверки обычно проводят по
результатам испытаний, α также β зависимости от геометрии конструкции. Следует
уделить специальное внимание методам проверки, которые должны использоваться β
«полевых» условиях эксплуатации. Следует избегать методов проверки β «полевых»
условиях, которые требуют оборудования η ресурсов за пределами возможностей
небольшого эксплуатанта или недоступны β отдаленных зонах эксплуатации
винтокрылых ЛА. Следует придерживаться консервативных (σ запасом) размеров для
обнаруживаемых трещин или других дефектов. Должны быть определены подходящие
интервалы проверок для обнаружения трещин, прежде чем они вырастут от
обнаруживаемых размеров до размеров, которые уменьшают остаточную прочность ниже
предела проектной прочности.
(C) Герметичные полости. Эта конструктивная особенность может
быть использована для обнаружения трещин, которые вызывают потерю давления β
полости (положительного или отрицательного). На потерю давления могут указывать
датчики или проникающий краситель, если доказано, что он является надежным
индикатором.
(Δ) Генерация вибрации. Это свойство должно рассматриваться
как σ точки зрения вибрации, указывающей на повреждение, так η σ точки зрения
увеличения усталостной нагрузки β результате вибрации.
Генерация шума. Если первоначальное повреждение вызывает (E)
отчетливый η безошибочный шум, который проявляется достаточно громко η
непрерывно, эта характеристика может быть использована при определении допустимого
повреждения без дополнительных специальных проверок.
(F) Дефектоскопия трещин σ помощью проволоки, фольги η τ.δ.
Проволочный датчик должен быть расположен β области, которая достаточно четко
определена. Этот метод подходит β тех областях, которые трудно контролировать иным
способом.
(iii) Многоэлементные конструкции. Конструкция σ несколькими
элементами может быть выполнена так, что повреждение или отказ β одном элементе
будет ограничиваться этим элементом, α остальная конструкция будет по-прежнему
обладать адекватной способностью выдерживать нагрузку, пока отказавший элемент не
будет обнаружен при проверке. Эти особенности должны обеспечить адекватную
независимость каждого режима отказа для конструкций σ многопутной передачей
нагрузки. При этой оценке рекомендуется использование полномасштабных изделий для
усталостных испытаний. Примерами нескольких одновременных повреждений, которых
следует избегать, являются:
(Α) Одновременный отказ или частичный отказ дискретных
элементов многопутной передачи нагрузок, работающих при сходных уровнях
напряжения.
(Β) Отказы, или частичные отказы β смежных областях, вызванные
перераспределением нагрузок после отказа единичного элемента.
