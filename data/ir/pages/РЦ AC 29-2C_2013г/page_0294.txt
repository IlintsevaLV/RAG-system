Отливки, рассчитанные на условия эксплуатационных нагрузок
Расчет прочности каждой испытываемой отливки, демонстрирующий, что критические
условия проектной эксплуатационной нагрузки подтверждаются данными … (смотрите
номер отчета, указанный β данном разделе). Ниже представлен расчет перегрузки при
статических испытаниях отливки:
1,15 χ проектную эксплуатационную нагрузку = проектной нагрузке текучести
1,50 χ проектную эксплуатационную нагрузку = проектной разрушающей нагрузке.
Отливки, рассчитанные только на условия аварийной посадки
Отливки данной категории рассчитывались, учитывая перегрузки при аварийной посадке
для проектной разрушающей нагрузки. Для данных отливок не требуется применение
критерия проектной нагрузки текучести, равной 1,15 от величины эксплуатационной
нагрузки. Нагрузки при испытании данных отливок могут представляться β виде
проектной разрушающей нагрузки на схемах нагружения для отдельных отливок,
указанных β части I данного отчета.
Процедуры испытаний
Ниже описаны процедуры, применяемые β зависимости от результатов первичного
испытания каждой отливки при статической нагрузке.
α. Если при первичном испытании критических отливок υ данной отливки
дополнительный коэффициент безопасности равен 1,5 (1,5 χ величину проектной
разрушающей нагрузки), данная отливка будет считаться приемлемой η дальнейших
испытаний не требуется.
β. Если при первичном(ых) испытании(ях) υ данной критической отливки
дополнительный коэффициент безопасности получится менее 1,5, но больше или равен
1,25, будут проводиться испытания двух дополнительных отливок для каждых
критических условий нагружения. Кроме того, υ каждой отливки должен быть
продемонстрирован минимальный дополнительный коэффициент безопасности для
отливок, равный 1,25.
χ. Если при первичном испытании или при одном из двух дополнительных
испытаний отливки дополнительный коэффициент безопасности получится менее 1,25 от
величины проектной разрушающей нагрузки или нагрузки текучести η достигает 1,15 от
величины проектной эксплуатационной нагрузки, данная отливка будет переработана η
снова испытана. Критерии нагрузки текучести также применимы для первых двух
процедур за исключением критических отливок, рассчитанных для условий аварийной
посадки.
ОБОРУДОВАНИЕ И МЕТОДИКА ПРОВЕДЕНИЯ ИСПЫТАНИЙ
Испытания отливок модели XYZ при статической нагрузке будут проводиться при
использовании креплений, сконструированных для моделирования установки отливок β
ЛА. Для приложения нагрузок при проведении испытаний по возможности будут
использоваться сопрягающиеся детали ЛА. Испытания при статической нагрузке будут
проводиться по возможности σ сопрягаемыми отливками, если критические нагрузки
совместимы σ данными σ сопрягаемыми отливками, β противном случае возможно
конструирование η изготовление креплений, моделирующих сопрягаемые детали.
Крепежные изделия, применяемые для установки отливок при проведения испытаний,
будут аналогичны изделиям, используемым β винтокрылом аппарате. Моменты затяжки
всех болтов η другие замечания по сборке будут выполняться β соответствии σ
инструкциями κ типу собираемой конструкции.
