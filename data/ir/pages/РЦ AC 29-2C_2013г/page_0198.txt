Обоснование прочности конструкции вспомогательных (рулевых) винтов (2)
требуется для обеспечения целостности при минимальной η максимальной расчетных
частотах вращения несущего винта, η при максимальной расчетной тяге несущего винта β
прямом η обратном направлениях. Тяга винта должна быть рассогласована σ крутящим
моментом несущего винта при максимальной мощности, согласно требованиям
§ 29.927(β).
(ι) Максимальная η минимальная эксплуатационные частоты вращения
винта, при полете без подачи мощности, составляют 95 процентов максимальной
расчетной частоты вращения η 105 процентов минимальной расчетной частоты вращения
соответственно.
(ii) Эксплуатационные частоты вращения винта, показанные во время
проведения официальных летных испытаний при участии представителей
FАА/авиационных властей, должны включать обозначенный 5 процентный запас
относительно расчетных частот.
(iii) Вспомогательный винт, β основном, имеет положительный η
отрицательный ограничитель шага, которые обеспечивают должное путевое управление
во всем эксплуатационном диапазоне винтокрылого аппарата. Ограничения по частоте
вращения винта при полете без подачи мощности, β основном, шире, чем ограничения по
частоте вращения винта при полете σ подачей мощности по причине требуемых
характеристик частоты вращения винта β режиме авторотации. Таким образом,
расчетные условия для вспомогательного винта касаются минимальной η максимальной
частот вращения винта β сочетании σ максимальным положительным η отрицательным
ограничителем шага соответственно. Тяга η конструктивный угол конусности винта, при
наличии такового, будут оказывать значительное влияние на проектные нагрузки винта.
Описание вариантов конструкции винтов η примеров обоснований являются слишком
объемными для включения β текст настоящих правил. Однако, "Руководство по
воздушным винтам» ANC-9 содержит принципы, которые могут быть применены при
проектировании рулевых винтов. Рулевые винты – это воздушные винты σ особой
конструкцией.
(iv) Для обеспечения взмаха η флюгерения лопастей β конструкции
рулевого винта обычно применяют подшипники. Нельзя допускать превышение
технических характеристик, заявленных производителем таких подшипников. Обычно
подшипники, применяемые β несущих η рулевых винтах, классифицируются согласно
ABEC (Комитет инженеров предприятий по производству кольцевых подшипников) по
классам 3, 5 или 7. Класс 7 является самым высококачественным из имеющихся β
настоящее время. Успешное завершение ресурсных испытаний, упомянутых β §§ 29.923 η
29.927, служит доказательством того, что использование определенного подшипника
является удовлетворительным.
(v) Расчеты должны включать специальные коэффициенты
безопасности, коэффициенты безопасности для отливок, коэффициенты безопасности
для шарниров η коэффициенты безопасности для фитингов, предусмотренные §§ 29.619,
29.621, 29.623 η 29.625, соответственно. При расчете установки рулевого винта должен
применяться коэффициент безопасности для фитингов, равный 1,15.
