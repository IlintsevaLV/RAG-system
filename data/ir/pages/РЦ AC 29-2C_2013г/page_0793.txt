(2) Ограничения путевой скорости. Хотя это специально η не предусмотрено
нормативами ограничений воздушной скорости, может возникнуть необходимость
определения ограничений «путевой скорости» для винтокрылых аппаратов σ колесными
шасси. Эти ограничения необходимы для демонстрации соответствия требованиям κ
характеристикам при наземной управляемости, требованиям κ прочности конструкции или
требованиям κ нагрузкам при стоянке на земле. Однако, из-за эксплуатационного
сходства предельных значений путевой скорости σ предельными значениями приборной
скорости, включение ограничений по путевой скорости β руководство по летной
эксплуатации под заголовком ограничений по скорости полета является общепринятой
практикой. Поэтому ограничения путевой скорости включены β данный параграф
настоящего РЦ. Ограничения путевой скорости должны устанавливаться σ
соответствующим запасом безопасности, чтобы учесть возможные неточности,
связанные σ необходимостью для пилота оценивать путевую скорость на основании
приборной воздушной скорости η имеющейся информации ο скорости η направлении
ветра β реальных условиях эксплуатации. Ниже приведены примеры ограничений
путевой скорости, которые потребовались β ходе предшествующих программ
сертификации типа:
(ι) Максимальная путевая скорость для взлета или посадки.
Максимально допустимая путевая скорость, которая может безопасно использоваться
для маневров взлета η посадки винтокрылых аппаратов σ колесными шасси, должна
определяться σ учетом ограничений для шасси или ограничений управляемости на земле.
Эта скорость должна быть достаточно высокой, чтобы соответствовать скоростям
касания при посадке при максимальной одобренной высоте по плотности для штатного
взлета η посадки.
Максимальная путевая скорость для торможения. Для винтокрылых (ii)
аппаратов σ колесными шасси необходимо определить максимальную скорость, при
которой могут приводиться β действие колесные тормоза без превышения максимальных
возможностей энергии торможения. Эта скорость должна подтверждаться β процессе
испытаний по всему одобренному диапазону режимов взлета η посадки винтокрылого
аппарата. Критическое сочетание полного веса η высоты по плотности σ точки зрения
энергии торможения может определяться путем расчетов, чтобы минимизировать
требуемый объем испытаний. Максимальная путевая скорость при торможении должна
быть достаточно высокой, чтобы осуществить торможение при посадке при максимальной
одобренной высоте по плотности.
(iii) Другие ограничения путевой скорости. Для некоторых конструкций
винтокрылых аппаратов σ полозковыми шасси может возникнуть необходимость
определения максимальной скорости касания при посадке для штатных режимов
эксплуатации, чтобы обеспечить соответствие требованиям κ конструкции.
Дополнительное оборудование, такое как флотационное оборудование, лыжное шасси η
τ.δ., которое присоединяется κ традиционным посадочным полозьям, требует
максимальных предельных значений путевой скорости при посадке, которые меньше
придельного значения для базового винтокрылого аппарата.
