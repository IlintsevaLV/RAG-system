ИСПЫТАНИЯ ОБРАЗЦОВ
Отливки, предназначенные для испытаний, представляются на рисунке AC 29.621-2 по
порядку номеров. Проходить испытания будут те отливки, υ которых, при проведении
расчетов, дополнительный коэффициент безопасности для отливок оказался менее 1,5.
Все направления показываются относительно винтокрылого аппарата, расположенного
носом вперед.
На основании требований рентгеноскопической проверки, β качестве образцов для
испытаний будут выбраны три отливки из первой партии самого низкого качества. Самая
низкокачественная из трех отливок будет отобрана для проведения первичного
тестирования отливок η получения его рентгеновского снимка или будет применен
стандарт ASTM для приемки следующих отливок конкретной детали до одобрения
последующих стандартов. Требуется проведение испытаний трех отливок при всех
критических условиях для каждой детали.
Проверка на соответствие
Для определения соответствия σ чертежами типовых конструкций каждая отливка до
проведения испытания будет подвергаться проверке на соответствие FАА/авиационными
властями. Отчет ο проверке на соответствие каждой отливки можно добавить β часть II,
«Результаты испытаний», данного отчета.
После испытаний образец будет отмечен постоянной маркировкой или гравировкой для
предотвращения его использования β винтокрылом аппарате.
Пример допустимых способов составления списка отливок указан на Рисунке
AC 29.621-2.
НАГРУЗКА ПРИ ИСПЫТАНИИ
Нагрузка(η) при испытании, прикладываемые κ каждой отливке, отражают критическое(ие)
условие(я) нагружения для данной отливки. Данные критические условия для каждой
отливки были определены посредством проектных критериев η подтвержденных данных,
одобренных FАА/авиационными властями.
