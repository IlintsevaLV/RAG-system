α. Пояснение.
(1) Поправка 29-39 приводит κ формированию § 29.49 на основе § 29.73, куда
были помещены требования для летных данных винтокрылых летательных аппаратов β
режиме висения. Β данном руководстве термин «режим висения» применяется κ ЛА,
находящимся β воздухе на определенной высоте над фиксированной географической
точкой независимо от ветра. Чистое висение достигается только β неподвижном воздухе.
Согласно § 29.49, летные данные β режиме висения должны быть (2)
определены на высоте, соответствующей процедуре взлета винтокрылого ЛА категории Аис учетом влияния земли для винтокрылого ЛА категории Β. Кроме того, для
винтокрылого ЛА обеих категорий должны быть определены летные данные на режиме
висения вне зоны влияния земли. Режим висения вне зоны влияния земли – состояние,
когда увеличение высоты над землей не требует дополнительной мощности
винтокрылого ЛА. Этот режим висения проявляется β отсутствии измеримого влияния
земли. Высота, на которой проявляется влияние земли, может быть меньше, чем один
диаметр несущего винта для винтокрылого ЛА малого полетного веса, существенно
увеличиваясь для винтокрылого ЛА большого полетного веса. Минимальная высота β
режиме висения вне зоны влияния земли для винтокрылого ЛА большого полетного веса
составляет примерно 1,5 диметра несущего винта между нижней частью винтокрылого ЛА
η поверхностью земли.
(3) Целью исследования летных данных β режиме висения является
определение потребной мощности при различных диапазонах взлетных весов,
температур воздуха η барометрических высот. При использовании безразмерных
коэффициентов мощности η коэффициентов тяги для нормирования η представления
результатов необходимо минимальное количество исходных данных, чтобы охватить
летные данные рабочего диапазона винтокрылого ЛА.
(4) Испытание для оценки летных данных β режиме висения должны
проводиться β диапазоне барометрических высот η весов, охватывающем изменения
этих величин при взлете η посадке. Также должны быть получены дополнительные
данные β условиях низких температур окружающей среды, особенно на больших высотах,
чтобы учесть возможное влияние сжимаемости.
(5) Минимальная высота висения, данные по которой должны быть получены
η впоследствии представлены β руководстве по летной эксплуатации, должна
соответствовать минимальной высоте при взлетных испытаниях. Процедуру определения
минимально допустимой высоты висения см. β разделе АС 29.51.
