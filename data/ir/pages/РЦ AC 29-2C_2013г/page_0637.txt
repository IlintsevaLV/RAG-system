AC 29.1157. § 29.1157 ОРГАНЫ УПРАВЛЕНИЯ ТЕМПЕРАТУРОЙ ВОЗДУХА
КАРБЮРАТОРА.
α. Пояснение.
(1) Этот раздел касается управления температурой воздуха поршневых
двигателей, снабженных карбюраторами.
(2) Для винтокрылых аппаратов, на которых установлено более одного такого
двигателя, для каждого двигателя должен быть предусмотрен отдельный орган
управления температурой воздуха, поступающего β карбюратор.
β. Процедура.
(1) Воздухозаборник двигателя должен быть снабжен средством
предотвращения η устранения обледенения путем нагревания воздуха перед его входом
β карбюратор.
(2) Управляемые вручную двухтактные системы σ жесткой проводкой
использовались для управления дроссельной заслонкой внутри воздухрзаборника.
Одним из способов показа соответствия является наличие одной такой системы для
каждого двигателя.
AC 29.1159. § 29.1159 ОРГАНЫ УПРАВЛЕНИЯ НАГНЕТАТЕЛЯМИ.
α. Пояснение.
(1) Данный раздел касается доступности органов управления нагнетателями
β кабине экипажа, если они установлены.
(2) Эти органы управления должны быть расположены таким образом, чтобы
они были легко доступны для пилотов или, при соответствующей конфигурации, для
бортинженера.
β. Процедура.
(1) Размещение η форма органов управления должны быть удобными η
доступными, η β достаточной степени отличимыми, чтобы исключить непреднамеренное
приведение β действие не того органа управления.
(2) Соответствие обычно демонстрируется путем оценки кабины.
