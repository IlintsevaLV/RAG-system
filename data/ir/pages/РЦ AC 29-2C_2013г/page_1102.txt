19. ОБЩИЕ УКАЗАНИЯ ПО ПРОЦЕДУРАМ – ПРОВЕРКИ
Общие инструкции включают процедуры для проверок симметрии ЛА.
См. Приложение Α, Α29.3 (β)(4). Информация необходима, когда заявитель указывает,
что требуются проверки симметрии ЛА. Такая информация обычно содержится β
главах, касающихся проверок симметрии ЛА, либо заявитель может включить раздел
для специальных осмотров, испытаний, проверок.
20. ОГРАНИЧЕНИЯ ПРИ ХРАНЕНИИ
Ограничения при хранении. См. Приложение Α, Α29.3 (β)(3). Информация необходима,
когда изготовитель винтокрылого аппарата, двигателя, устройства или расходных
материалов устанавливает ограничения при хранении.
α. Существуют различные ограничения при хранении. Заявитель должен
определить такие требования, предусмотреть процедуру хранения η средства для
обеспечения ограничений при хранении.
β. Такая информация обычно содержится β главах, определяющих
хранение.
21. МЕТОДЫ СПЕЦИАЛЬНОГО КОНТРОЛЯ.
Подробная информация для применения методов специального контроля,
включая радиографические η ультразвуковые испытания, где такие процессы
необходимы. См. Приложение Α, Α29.3 (δ). Информация необходима, когда заявитель
устанавливает, что требуются методы специального контроля.
α. Инструкции ICA должны включать оборудование, необходимое для
специального контроля.
β. Инструкции ICA должны содержать процедуры проведения таких
испытаний, включая любые меры предосторожности. См. главу 1, параграф 13.
χ. Такая информация обычно содержится β главах, требующих методов
специального контроля, либо заявитель может включить раздел для специальных
осмотров, испытаний, проверок.
22. ЗАЩИТНАЯ ОБРАБОТКА
Информация, необходимая для защитной обработки конструкции после
проверки. См. Приложение Α, Α29.3 (ε). Информация необходима, когда заявитель
определяет, что требуется защитная обработка конструкции.
α. Инструкции ICA должны включать процедуры для проведения защитной
обработки.
β. Инструкции ICA должны определять типы используемых материалов.
χ. Инструкции ICA должны содержать меры предосторожности,
связанные σ защитной обработкой.
