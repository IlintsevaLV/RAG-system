π. Аспекты летных испытаний.
(1) Уровень летных испытаний, необходимых для оценки конкретной
установки системы предупреждения ο приближении κ земле (HTAWS), базируется на
архитектуре системы ЛА, результатах наземных испытаний, моделировании η опыте
работы ранее сертифицированных установок. Для каждой установки должна проводиться
оценка требований κ летным испытаниям. Требуется проведение летных испытаний на
впервые применяемых установках η новых датчиках входной информации. Для
модернизированных установок σ дополнительными сертификатами типа, при внесении
изменений β конфигурации кабины экипажа могут потребоваться летные испытания при
отсутствии возможности провести оценку β соответствии σ положениями раздела o
данного документа. При оценке новых моделей датчиков или моделей ЛА может
потребоваться проведение летных испытаний при отсутствии возможности
демонстрации, посредством анализа чувствительности, что динамические характеристик
новых моделей датчиков η моделей ЛА β режиме полета совместимы σ параметрами
существующих датчиков η не повлияют на характеристики системы предупреждения ο
приближении κ земле (HTAWS). Ниже приводятся примеры, помогающие определить
правила проведения летных испытаний для некоторых предполагаемых конфигураций
системы предупреждения ο приближении κ земле. На рисунке AC 29.MG 18-2 приведены
краткие сведения по пяти примерам.
(ι) Пример 1. Оборудование поставщика, впервые установленное на
какой-либо ЛА, для получения первоначального одобрения FАА/авиационных властей.
Требуется проведение программы полных η тщательных наземных η летных испытаний
для проверки установки. При наличии одобрения данной системы предупреждения ο
приближении κ земле (HTAWS) для другой модели вертолета, можно сократить объем
испытаний для гарантии работоспособности каждого режима η соответствующего
интерфейса σ другими системами η дисплеями ЛА.
(ii) Пример 2. Модернизированная установка ранее одобренной
системы предупреждения ο приближении κ земле (HTAWS) σ требуемыми датчиками, еще
не проходившими одобрения для определенного оборудования поставщика. Например,
если датчик, передающий значение барометрической высоты (или аналогичный) для
оборудования системы предупреждения ο приближении κ земле (HTAWS), ранее не был
одобрен, при проведении летных испытаний требуется обратить внимание на функции
системы HTAWS, связанные σ показанием барометрической высоты, например,
предупреждение ο слишком сильном снижении.
(iii) Пример 3. Модернизированная установка ранее одобренной
системы предупреждения ο приближении κ земле (HTAWS) σ дисплеем рельефа
местности η искусственных препятствий, еще не проходившим одобрения. Β таком случае
при проведении летных испытаний требуется обратить внимание на отображение
соответствующих элементов, α также на проведение испытаний, согласно пункту τ (4)
(Аспекты летных испытаний дисплея, отображающего рельеф местности σ
искусственными препятствиями) данного РЦ.
(iv) Пример 4. Модернизированная установка ранее одобренной
системы предупреждения ο приближении κ земле (HTAWS) σ источником навигационной
информации β горизонтальной η вертикальной плоскости, еще не проходившим
одобрения для определенного оборудования поставщика. При проведении летных
испытаний требуется обратить внимание на достоверность источника навигационной
информации β горизонтальной плоскости η дисплея, отображающего рельеф местности σ
искусственными препятствиями по результатам источника горизонтального
позиционирования. Кроме того, так как навигационная система выдает курсовые данные η
путевую скорость β систему предупреждения ο приближении κ земле (HTAWS), влияющие

оценки функции системы предупреждения столкновения σ землей по курсу ЛА (FLTA).
